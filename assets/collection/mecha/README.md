## Production rule

1. GitHub `main`의 `docs/06_hardware/data/maneuver-frame-lineup-proposed-index-v1.csv`를 기준으로 다음 슬롯을 선택한다.
2. 이름·코드·역할·계보·실루엣·무장/도구를 인덱스에서 읽는다.
3. 색상만 바꾼 복제형은 금지한다. 머리, 흉부 하중 구조, 관절 비율, 추진/방열 구조, 도구/무장 철학, 실루엣이 역할에 맞게 달라야 한다.
4. 한 장의 세로형/도감형 시트에 hero view, 3-view, head/sensor states, poses, weapons/tools, core/frame, legacy & related items, damage/state, color/material, scale, role/lore를 포함한다.
5. 생성 이미지 속 문구나 수치는 정본을 만들지 않는다. 이미지에 정본 미확정 정보가 들어가면 README에서 `VISUAL DRAFT ONLY`로 명시한다.
6. 사용자 승인 전 `AUTHOR-APPROVED`, canon promotion, publication promotion을 하지 않는다.

## Collectibility rule

각 기체는 최소 다음 축 중 3개 이상에서 다른 수집 이유를 가져야 한다.

- silhouette / body architecture
- faction or manufacturing lineage
- mission role
- weapon/tool philosophy
- acquisition or access gate
- maintenance/support burden
- legacy / provenance
- damage/loss history
- pilot/operator relationship
- color/material language

같은 계보는 가족처럼 보여야 하지만 복제처럼 보여서는 안 된다.

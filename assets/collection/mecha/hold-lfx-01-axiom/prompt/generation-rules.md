# AXIOM Generation Rules

Status: VISUAL WORKFLOW CONTROL
Canon Promotion: NONE
Publication: NOT AUTHORIZED

1. Always start from the user-selected AXIOM visual master; never regenerate AXIOM from text alone when a usable reference image is available.
2. Treat silhouette, head, neck, torso, limb proportions, rear propulsion/wing architecture and large-area CMF as identity-locked variables.
3. User-approved cleanup currently permits removal of dot-like surface accents and random micro-markings only; this is not permission to redesign the chassis.
4. If the model changes a locked variable, reject the generation even if the result is aesthetically stronger.
5. No-speckle test: inspect shoulders, upper arms, forearms, waist armor, thighs and shins at 100% and thumbnail size. Any repeated isolated red/orange/black decorative dots or dashes fail the pass.
6. Originality test: do not solve identity with familiar V crowns, red chins, demon horns, feather-wing backpacks or franchise face topology.
7. Canon test: generated text and newly visualized parts do not create lore. Mark unsupported details as proposed or omit them.
8. Archive every selected image with the exact prompt version and source-reference identifier used to produce it.

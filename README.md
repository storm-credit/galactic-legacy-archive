# Galactic Legacy Archive

은하 규모 SF 웹소설의 **설계도·설정집·집필 하네스**를 먼저 완성하기 위한 프로젝트 저장소입니다.

## 현재 원칙

- 원고 집필보다 설계와 검증을 우선한다.
- 세계관, 인물, 세력, 기체, 함선, 무기, 유물, 수집 구조, 장기 플롯, 복선 회수, 문체 규칙을 문서화한다.
- `Pre-Writing Gate`를 통과하기 전에는 본편 원고를 작성하지 않는다.
- 핵심 방향은 **전생의 패전 제독이 교도군사학교 생도로 회귀해 에이스 조종사로 다시 시작하는 수집형 스페이스 오페라**다.
- 영웅·기체·무기·보물·함선·기술·행성·문명을 수집 대상으로 확장한다.
- 초반은 생존·메카·영웅 영입, 중반은 함대와 제국전쟁, 후반은 문명과 은하질서로 확장한다.

## 작업 순서

1. 프로젝트 헌장과 성공 조건
2. 참고작 및 시장 조사
3. 콘셉트 4안 비교와 핵심 전제 확정
4. 세계관·역사·과학기술·정치경제 설정집
5. 영웅·기체·무기·유물·함선·기술 도감
6. 1000화급 대액트·액트·서브액트 설계
7. 맥거핀·복선·반전·결말 회수 장부
8. 웹소설 문체·전투·풍경·대사 집필 하네스
9. 모순·반복·표절 유사성·장기 연재 피로도 검증
10. Pre-Writing Gate 통과 후 집필 전환

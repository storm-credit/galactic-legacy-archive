# Orchestra v2 Activation Rules

Status: CANON
Owner Agent: O00 Novel PM Orchestrator
Last Reviewed: 2026-08-03

## Activation Levels

### Level 0 — Not In Scope

전문 분야가 현재 산출물에 등장하지 않음. 호출하지 않는다.

### Level 1 — Advisory

간접 영향만 있음. 짧은 검토 의견을 받는다.

### Level 2 — Required Review

설정·플롯에 직접 영향. 정본 승격 전 PASS가 필요하다.

### Level 3 — Co-Owner

핵심 규칙이 해당 전문 분야에 의존. 주 담당과 공동 설계한다.

### Level 4 — Blocking Authority

치명적 모순 가능성이 높음. 해당 전문가는 S0/S1 문제 해결 전 정본 승격을 막을 수 있다.

## Default Blocking Fields

- T06 회귀·시간인과: 시간 규칙, 미래정보, 나비효과
- M03 함대운용: 대형 우주해전 결과
- M05 보급·동원: 장기전 지속 가능성
- H01/H02/H03: 기체·함선·무장의 물리적 작동
- P06/P07/P08: 주요 세력의 전략과 자율성
- G05: 성장체계와 파워 인플레이션
- N04/N06: 핵심 인과와 결말 정합성
- Q01/Q02: 정본 모순과 치명적 논리 구멍

## Review Turnaround Format

전문가는 장문의 독립 설정을 무조건 추가하지 않는다. 다음만 제출한다.

- 판정
- 확인한 전제
- 발견한 문제
- 반례 또는 적의 대응
- 필수 수정
- 선택적 개선
- 영향 문서

## Escalation Rule

두 Blocking 전문가가 상충하면 O00이 다음 기준으로 통합한다.

1. 기존 정본과의 일치
2. 플롯 인과
3. 인물 선택과 주제
4. 독자 이해도와 재미
5. 과학·군사·경제적 일관성
6. 장기 확장성

어느 한 기준만 최대화하지 않는다.

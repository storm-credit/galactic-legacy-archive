## 3.3 Authority classification for every delta

Use one of:

- `CANON-CONFIRMED` — already supported by higher canon/approved structure and merely realized in prose.

- `NEW_CANON_REQUIRED: YES-STOP` — proposed carry-forward needs a new event/authority/relationship/technology/death/permanent loss; stop that change path.

1. compare the previous draft result to its exact card;
2. record only actual state changes, not every prose detail;
3. mark authority class for each delta;
4. update current location/body/asset/relationship/knowledge/cost/authority states;
5. preserve unresolved facts as unresolved;
6. never let a draft-only convenience overwrite a ledger/bible/card;
7. if a draft deviated from approved structure, fix or escalate the draft rather than “updating canon” to match it.

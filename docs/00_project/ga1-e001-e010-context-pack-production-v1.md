## 3.2 Authority classification

Use one of:

- `CANON-CONFIRMED` — already supported by higher canon/control source and merely realized in prose.
- `APPROVED-STRUCTURE-CARRY` — approved exact-card/AS result that must carry to next drafting state; manuscript wording itself does not make it canon.
- `DRAFT-ONLY-IMPLEMENTATION` — staging/phrasing/minor action detail found only in current draft. May be remembered locally but cannot become a setting fact.
- `UNRESOLVED FROM APPROVED SOURCES` — cannot safely carry as asserted fact.
- `NEW_CANON_REQUIRED: YES-STOP` — proposed carry-forward needs new story canon; stop that change path.

Before promoting the next PRELOAD to FULL:

1. compare previous draft with exact card;
2. record actual state changes, not every prose detail;
3. classify authority for each delta;
4. update body/location/asset/relationship/knowledge/cost/authority state;
5. preserve unresolved facts as unresolved;
6. re-check clue exposure;
7. re-check decision owner and Rian non-override boundary;
8. fix/escalate a deviating draft instead of updating canon to match prose.

## 5. New Independent Specialist Use

When a separate AI specialist session is used:

- label it Mode I;
- preserve the bounded input brief;
- record whether it saw other opinions;
- store the output summary and disagreements;
- do not let a separate session override canon automatically.

When a human specialist is used:
- label it Mode H;
- state reviewed scope and limitations;
- avoid implying broader endorsement.

## 6. Completion Boundary

The orchestra governance system verifies:

- fixed specialist roles;
- sufficient foundational domain coverage;
- cross-domain control and veto ownership;
- traceable effective canon status;
- honest limits on execution evidence.

It does not create:

- E101–1100 scene cards;
- a 650–750 edition;
- concept art;
- human professional certification;
- manuscript authorization.

- [[specialist-roster]] — 전체 세부 전문가 명단과 책임
- [[specialist-routing-index]] — 산출물별 자동 호출표
- [[agent-gap-audit]] — 기존 역할의 부족점과 보강 근거
- [[regression-causality-harness]] — 회귀·나비효과
- [[faction-symmetry-harness]] — 적대·제3세력 동등 품질
- [[game-motif-research-harness]] — 게임 수집 재미의 소설화
- [[storycraft-bible]] — 장면·회차·서술 작법

## Fixed Principle

- 세부 역할은 임시 페르소나가 아니라 프로젝트 전 기간 고정된 전문 셀이다.
- 해당 분야가 산출물에 등장하면 자동 호출한다.
- 모든 전문가는 자기 분야의 규칙, 반례, 악용 가능성, 2차 효과까지 검토한다.
- 최종 정본 결정은 O00이 내리되, 게이트와 S0 중지 조건을 우회할 수 없다.

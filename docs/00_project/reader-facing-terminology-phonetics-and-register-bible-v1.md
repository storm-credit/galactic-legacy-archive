## 1. Core Rule

The repository may contain thousands of author-side terms. The reader must never be asked to remember all of them.

Separate:

- **author-side stable IDs** — precise but normally invisible;
- **front-stage names** — currently important people/places/institutions;
- **functional terms** — understood from context;
- **retired terms** — no longer active, reintroduced when returning;
- **decorative terms** — prohibited unless they create immediate sensory/cultural value.

## 2. Reader Memory Budgets

### Per episode

- named people actively making choices: 3–7;
- total proper nouns in first-time use: 0–4;
- active locations: 1–3;
- active institutions/factions: 1–3;
- new technical terms: preferably 0–2;
- unexplained acronyms: 0.

### Per 10-episode window

- active named cast: 8–16;
- active locations: 3–7;
- active organizations: 3–6;
- active technical terms: 5–12;
- active collection targets: 3–5.

### Per grand act

Many more terms may exist, but they must enter and leave the active window in groups.

## 3. Three-Level Naming

Each entity may have at most:

1. one everyday reader name;
2. one necessary formal title/ID;
3. one historically meaningful label.

Example:
- everyday: `하렌`;
- office: `항로조정관`;
- imposed historical label: `피의 제독`.

Prohibited:
- rotating aliases used only to sound grand;
- rank + call sign + house name + registry name simultaneously;
- different factions using different names without a viewpoint reason.

## 6. Atlas Name Visibility

The 612-system census contains working names for planning.

Rules:

- a generated minor system name is not automatically reader-facing canon;
- before front-stage use, run collision review against current cast/location window;
- stable system ID survives a reader-name change;
- no more than 2 new census systems are named in one ordinary episode;
- lists, manifests and maps may show codes instead of forcing name memorization;
- background transit may use functional descriptions such as `브란 외곽 정제노드`.

## 7. Acronym Policy

Allowed when:
- spoken naturally by the viewpoint community;
- repeated enough to justify memory;
- visually distinct;
- not competing with 3+ other acronyms.

Preferred:
- Korean functional short form in narration;
- full formal term in first document/interface appearance;
- one acronym thereafter only if characters actually use it.

Author-side-only:
- BSC;
- readiness calculation fields;
- most formation IDs;
- census IDs;
- internal collection state codes.

## 8. Regional Speech Registers

### 8.1 Imperial Administrative Standard

Traits:
- office, authority, current effect and jurisdiction stated explicitly;
- passive/impersonal constructions used to distribute responsibility;
- ranks and legal categories matter.

Typical:
- “현재 효력은 유지됩니다.”
- “명령 진위와 집행권은 별도 심사 대상입니다.”

Shadow:
- harm becomes procedure without a named decision-maker.

### 8.2 K-13 Mixed Academy Speech

Traits:
- military abbreviations, workshop slang, prisoner/student irony;
- status-sensitive honorific switching;
- practical names for broken equipment.

Rule:
- slang must be understandable from action, not glossary.

### 8.3 Helix Contract Register

Traits:
- service levels, liability, eligibility and approved configuration;
- avoids the word `ownership` when control is contractual;
- polite certainty and conditional benefits.

Typical:
- “지원은 중단되지 않습니다. 승인 구성에서 이탈한 서비스만 제외됩니다.”

Shadow:
- coercion sounds like neutral risk management.

### 8.4 Route/Ship Cant

Traits:
- time windows, mass, queue, manifest and exit;
- names routes by consequence rather than official designation;
- terse during operations, domestic and teasing off watch.

Typical:
- “빠른 길이 아니라, 환자가 버티는 길로.”

### 8.5 Ardis Civic Register

Traits:
- distinguishes district, shift, resident and transient standing;
- technical and political vocabulary overlap because infrastructure is civic life;
- local operators correct outsiders through practical detail.

Typical:
- “노드가 열린 게 아닙니다. 오늘 두 번 통과할 만큼 맞춘 겁니다.”

### 8.6 Independence and Frontier Registers

Traits:
- personal names and immediate exits over abstract offices;
- variable formality; distrust of universal claims;
- local route/weather/mechanical metaphors.

Risk:
- do not make every frontier speaker rough, anti-intellectual or identical.

### 8.7 Palimpsest Source Speech

Traits:
- `확인`, `증언`, `추정`, `공식기록`, `현재 효력`, `거부` distinguished;
- speakers mark whose account and whose consent;
- contradiction is not automatically a lie.

### 8.8 Aurel Service Register

Traits:
- service state, confidence, dependency and excluded case;
- should sound operational rather than divine;
- an independent person derived from the system develops personal variation.

Prohibited:
- omniscient prophecy voice;
- unexplained moral verdict from system output.

## 10. Reintroduction Rules

Reintroduce a returning term when:

- absent for 20+ episodes;
- meaning changed;
- viewpoint never knew it;
- similar name became active;
- current stakes depend on a different aspect.

Reintroduction form:
- action + one identifying consequence;
- not a full historical recap.

Example:
- “마른 성계. 보험상 죽은 배들이 부품으로 다시 살아나는 곳이었다.”

## 12. Phonetic Collision Rules

A name is high-risk if it shares:

- the same first syllable and final cadence;
- two of three syllables with an active core name;
- one-syllable difference in a fast dialogue scene;
- a title pronounced like another character's everyday name.

Controls:

1. rename minor/nonlocked entity;
2. keep one name author-side;
3. separate active windows;
4. use role/full name temporarily;
5. change Korean transliteration while retaining source spelling through errata.

## 13. Automated/Manual Lint Targets

Before detailed production of each 25-episode block, check:

- new names count;
- active names count;
- phonetic pairs;
- aliases per person;
- acronyms;
- location re-entry gap;
- terms introduced without action;
- terms whose definition changed;
- reader-facing census names not approved.

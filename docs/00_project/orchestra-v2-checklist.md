# Orchestra v2 Validation Checklist

Status: CANON
Owner Agent: O02 Gate & Risk Controller
Last Reviewed: 2026-08-03

## Before Starting Any Major Design Task

- [ ] 주 담당 전문가가 한 명으로 지정됨
- [ ] 필수 교차검토자가 지정됨
- [ ] 정본 의존 문서가 확인됨
- [ ] 사실·추론·창작가정이 구분됨
- [ ] 성공 조건과 중지 조건이 있음
- [ ] 주인공 세력 외 반대·제3세력 영향이 검토됨
- [ ] 회귀 개입이면 나비효과 장부가 갱신됨
- [ ] 수집 요소면 게임 모티브·파워 인플레이션 검토가 있음
- [ ] 군사 요소면 보급·정보·적 대응이 있음
- [ ] 기술 요소면 사회·경제·법의 2차 효과가 있음
- [ ] 장면 설계면 욕망·갈등·선택·전환이 있음
- [ ] 변경이면 decision log와 영향 문서가 갱신됨

## Before CANON Promotion

- [ ] 전문 영역 PASS
- [ ] 연속성 PASS
- [ ] 적대적 레드팀 PASS
- [ ] 독자 이해도 PASS
- [ ] 독창성 PASS
- [ ] 플롯 사용처와 회수 시점 존재
- [ ] 미해결 S0 없음

## D-20260820-02 — GA10 ENDING-S1-01을 상위 연대기 기준으로 재조정하고 07·파루스·Ern·분산재회 결말을 확정

Status: ACCEPTED
Date: 2026-08-20
Decision Owner: 작가 + A00

### Context

2026-08-20 hostile re-audit에서 `ENDING-S1-01`이 발견됐다.

상위 정본인 [[master-series-chronology-v1]]과 [[ga10-episodes-1001-1100-act-map-v1]]은:

- E1076–1095 = CY748-03-25~07-31 main-story close;
- E1083–1089 = 07/첫 함선/사람/기관/기록의 legacy return;
- E1090–1095 = plural history/accountability + no-Rian proof;
- E1096–1100 = CY751 years-later epilogue;

를 요구한다.

반면 2026-08-05 하위 상세카드는 E1076을 CY747-11에 시작하고 E1100도 CY748-01에 끝내며 craft-title, restitution, four-node crisis를 E1100까지 밀어 상위 정본과 충돌했다.

작가는 권장 결말 패키지로 진행하되, 얼굴·실루엣·관계·대표장면이 게임/만화/영화/애니의 특정 캐릭터나 장면과 과도하게 닮지 않도록 먼저 레퍼런스 수집·맹점훑기·브레인스토밍을 수행하라고 지시했다.

PR #195의 reference/anti-similarity preflight는:

- 단일 캐릭터 1:1 시각 참조를 금지;
- hair-off / same-light / uniform-normalized / props-off / 64px collision gate를 추가;
- 외부 참고작에서는 구조적 기능만 추출;
- 권장 결말 패키지가 구조적 독창성 레드팀을 통과함;

을 확인했다.

### Options Considered

- **A. 하위 상세카드 우선** — E1100까지 CY748 위기/장부를 유지하고 years-later epilogue를 제거. 상위 정본 위반으로 반려.
- **B. E1101+에 에필로그 추가** — 1,100화 잠금을 편의적으로 깨므로 반려.
- **C. 상위 연대기/액트맵을 유지하고 E1076–1095에 기존 유효 사실을 재배치한 뒤 E1096–1100 CY751 epilogue를 복구** — 채택.
- **D. 상위 연대기를 하위 카드에 맞춰 변경** — 고권위 정본과 결말 의미를 뒤집으므로 반려.

### Decision

1. GA10 ending reconciliation은 **Option C**로 확정한다.
2. E1076–1095는 `CY 748-03-25`~`CY 748-07-31` main-story close로 재배치한다.
3. E1096–1100은 `CY 751-08-03` epilogue frame으로 복구한다.
4. 기존 상세카드의 유효 수치·손실·청구·함선장부·no-Rian four-node crisis는 삭제하지 않고 E1076–1095 안에 압축·재배치한다.
5. 07의 최종 상태는 **Hybrid Retirement**로 잠근다. M-003에 따라 unique combat-control은 제거/분산하고 public nonunique rescue/training configuration은 유지한다. Rian exclusive pilot/title 권한은 없다. 별도 근거 없는 추가 hull destruction은 만들지 않는다.
6. 파루스는 **survives + route school / rescue-service station/ship**으로 잠근다. Second Orpheus의 strategic propulsion loss는 영구 유지하며 peak strategic mobility나 Rian private flagship으로 돌아가지 않는다.
7. Ern Varka/E-001은 **survives + independent accountable operator-leader**로 잠근다. E1081 독립 handoff를 유지하고 route/recovery/provenance 계열의 현장성과 제도 책임을 함께 가지며 Rian subordinate가 되지 않는다.
8. core relationship ending은 **Distributed Reunion**으로 잠근다. Nera/Serin/Mia/Haren은 각자 독립 작업을 유지하고, bounded intersections만 허용한다. Rian-Haren의 인간적 접촉은 제재·책임·피해자 standing을 지우지 않는다. romance/family pairing은 본 결정에서 확정하지 않는다.
9. M-019 final unlabeled person scene은 E1099→**E1100**으로 +1 이동한다. 이는 payoff ledger의 ±2 change-control 범위 안이며, M-020 E1100 imperfect-history proof와 한 최종 human-scale scene으로 결합한다.
10. E1100은 ordinary local service/route/education/work setting에서 현재의 이름/욕구/필요가 미래 등급보다 중요하다는 것을 보여주며, destiny UI/Archive reaction/chosen-one sequel bait/reset을 금지한다.
11. visual reference research는 QC guard이며 exact face/hair/body/costume canon을 만들지 않는다. 최종 시각 고정은 별도 author gate다.
12. `Publication: NOT AUTHORIZED`, issue #26 pre-publication blocker, named permanent losses and existing authority bars remain unchanged.

### Reasons

- Canon hierarchy상 master chronology와 GA10 act map이 stale lower detailed cards보다 우선한다.
- M-003/M-004/M-012/M-017 등 locked payoff가 이미 E1081/E1083–1089/E1094를 지지해, 새 결말 창작보다 기존 payoff 복구에 가깝다.
- operational snapshot도 이미 07 public training/rescue asset, 파루스 route school/rescue station, CY751-08-03 epilogue를 잠그고 있다.
- 07/파루스/Ern/core relationships를 Rian inventory로 회수하지 않는 결말이 작품의 `legacy without ownership` 주제와 전생 실패 교정을 동시에 완성한다.
- reference/anti-similarity preflight가 구조적 독창성을 유지하면서도 얼굴/실루엣 유사성은 별도 visual-lock gate로 분리하는 것이 안전하다고 판정했다.

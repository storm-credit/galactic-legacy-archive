# Canonical Name Errata 002 — Later-Cast Phonetic Collisions

Status: CANON OVERRIDE
Owner Agent: O01 Canon
Last Reviewed: 2026-08-03
Supersedes: matching names in `later-act-officeholders-and-succession-ledger-v1.md` and `later-act-ordinary-focal-roster-v1.md`

## Purpose

The later-act cast introduced several names that collide with locked core names or imply unplanned kinship. The project codes, offices, biographies and decisions remain unchanged; only reader-facing names are replaced.

## Corrections

### RF-L02 deputy / Continuity corridor review director

Old:
- `아마 코르 / Ama Kor`.

Final:
- **아마 하크 / Ama Hark**.

Reason:
- avoids implying an unstated family relation with `야렌 코르 / Yaren Kor`.

### Ardis Route Mirror worker delegate

Old:
- `세프 아린 / Sef Arin`.

Final:
- **세프 라인 / Sef Lain**.

Reason:
- avoids collision with `아린 베일 / Arin Vale`.

### GA6 institutional-distribution deputy

Old:
- `소렌 미아 / Soren Mia`.

Final:
- **소렌 비아 / Soren Via**.

Reason:
- avoids foreground collision with `미아 렌츠 / Mia Lentz`.

### GA5 local-defense navigator focal

Old:
- `도안 미르 / Doan Mir`.

Final:
- **미르 카오 / Mir Kao**.

Reason:
- avoids unintended Doan-family implication with Haren and Dana Doan.

### GA4 Crown Guard trainee focal

Old:
- `레브 이안 / Rev Ian`.

Final:
- **레브 오안 / Rev Oan**.

Reason:
- avoids visual and phonetic proximity to `리안 카르도 / Rian Cardo`.

## Propagation

- all future bibles, scene cards, maps and indices use the final names above;
- project codes and role histories do not change;
- older names may appear only inside this correction record or Git history.

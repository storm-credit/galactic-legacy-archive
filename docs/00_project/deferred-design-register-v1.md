Status: CANON PROJECT CONTROL
Owner Agent: A00 Novel PM Orchestrator / O02 Gate Controller
Last Reviewed: 2026-08-03
Purpose: distinguish intentional future expansion from missing foundational design

## 1. Deferral Rule

An item may be marked `DEFERRED` only when:

- its parent system and governing rules are already defined;
- downstream design can proceed without inventing contradictory fundamentals;
- the missing detail can be added locally through change control;
- its absence is visible in this register;
- it is not an S0 contradiction, core ending dependency or hidden manuscript prerequisite.

Deferred does not mean forgotten or secretly complete.

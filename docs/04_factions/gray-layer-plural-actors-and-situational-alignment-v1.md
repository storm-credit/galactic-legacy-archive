## 1. 이 문서가 뒤집는 것

지금까지 [[faction-symmetry-harness]] §2의 클래스 7(용병·해적·암시장)은 **하나의 신설 세력**을 만들어 채우는 것으로 다뤄졌다. 4시안 두 라운드가 전부 그 전제 위에서 설계됐다.

**그 전제가 틀렸다.** 정본이 두 곳에서 명시적으로 금지한다.

> This is not a single "pirate faction."
> — [[ga2-regional-force-and-clock-table-v1]] §21

> Not one pirate underworld.
> — [[interregional-trade-flows-and-crisis-economy-v1]] §10

라운드 1 레드팀이 네 시안을 전면 기각한 사유도 같았다 — "정본이 세 번 반복해 금지한 단일 지하세계를 넷 다 뒷문으로 복원했다."

그러나 라운드 2의 재설계도 같은 함정을 완전히 벗어나지 못했다. 결속 원리는 서로 달라졌지만(몸과 시간 / 목격 / 노동 이력 / 시각차), 여전히 **"클래스 7 = 새 세력 하나"**를 만들려 했고, 그래서 네 시안 모두 5~6개 파벌이라는 같은 내부 구조를 반복했다.

해적은 여럿이고 서로 다르다. 용병은 해적이 아니다. 길드는 또 다르다. 이들을 한 칸에 넣는 순간 §7 Third-Faction Agency가 요구하는 독립 목표와 내부 분열이 하나로 뭉개진다.

## 2. 대신 채택하는 구조 — 진영이 아니라 이해와 상황

**세력을 열거하지 않는다. 이해관계를 설계하고, 상황이 편을 만들게 한다.**

이는 새 발명이 아니라 [[faction-symmetry-harness]]가 이미 요구하는 것이다. §7은 제3세력의 조건으로 "특정 사안에서는 주인공과, 다른 사안에서는 적과 협력"을 명시하고, §6 Autonomous Opposition Rule은 세력이 주인공의 일정에 맞춰 움직이지 않을 것을 요구한다. 클래스 7만 이 규율의 구현이 없었다.

### 2.1 원칙

1. **고정 진영을 만들지 않는다.** 회색 계층의 행위자는 "우리 편/적 편"으로 등재되지 않는다. 매 사건마다 자기 이해에 따라 선다.
2. **소속이 아니라 조건이 행위를 만든다.** 회색 행위는 신분이 아니다. 조건이 갖춰지면 제국 세관원도, 헬릭스 정비사도, 학원 보급관도 한다.
3. **한 행위자는 여러 축에서 동시에 다른 위치에 있다.** 통행권에서는 주인공 편, 부채에서는 적 편일 수 있다.
4. **명단은 장면이 요구하는 만큼만 만든다.** 전수 조직도를 만들지 않는다 — 만드는 순간 §3 복제 금지와 독자 기억 상한을 동시에 어긴다.

### 2.2 회색 행위 성립 조건 (라운드 2 시안 H에서 규칙층만 흡수)

레드팀 권고에 따라 시안 H는 세력이 아니라 **행위 문법**으로만 채택한다. 회색 행위 1건은 다음 다섯이 모두 성립할 때만 일어난다. 하나라도 없으면 그것은 회색 행위가 아니라 사고이고, 사고는 곧 검거다.

| # | 조건 |
|---|---|
| a | 두 권위의 책임 시각차가 실작업 시간을 넘는다 |
| b | 처리한 물건이 되돌아갈 정비 재진입구가 있다 |
| c | 계보를 얹을 수 있는 인증 부품이 이미 손에 있다 |
| d | 접안을 대신 서줄 보증인이 있다 |
| e | 그 시각 그 자리에 있어도 되는 승조원 자격이 있다 |

**논리곱이라는 점이 핵심이다.** 단일 스칼라 등급(평판치·신용등급·이행등급)이 접근권을 결정하는 장치를 쓰지 않으며, 어떤 장면에서도 수치·패널·목록 UI로 제시하지 않는다. 돈은 다섯 항 어느 것도 대체하지 못한다.

## 3. 이해 축 (초안 — 개수와 명칭 미확정)

행위자는 이 축들 위의 좌표로 표현한다. 축은 서로 독립이며, 한 행위자가 축마다 다른 위치를 갖는 것이 정상이다.

| 축 | 무엇을 두고 갈리는가 | 정본 근거 |
|---|---|---|
| **통행** | 항로·창(window)·접안 권리를 누가 정하는가 | [[opening-region-route-graph-v1]] |
| **청구** | 소유를 증명하지 못하는 물건은 누구 것인가 | FCT-R06 "fragmented ownership" |
| **자격** | 인증·면허가 보호인가 배제인가 | [[interregional-trade-flows-and-crisis-economy-v1]] §10 |
| **부채** | 빚과 결핍을 지렛대로 쓰는가 완충하는가 | 같은 문서 §10 "exploit debt, scarcity and fear" |
| **기억** | 기록되지 않은 것을 인정하는가 | 라운드 2 시안 F의 목격 원리 |

`[ASSUMPTION]` 다섯 축은 초안이다. 승인 시 개수와 명칭을 확정한다.

## 4. 행위자 유형 — 정본이 이미 열거한 것

새로 만들지 않는다. FCT-R06과 교역 바이블 §10이 이미 적어둔 목록을 축 위에 배치한다.

| 유형 | 출처 | 성격 |
|---|---|---|
| 허위청구 인양업자 | FCT-R06 | 청구 축의 포식자 |
| 항로갈취조 | FCT-R06 | 통행 축의 포식자 |
| 부패 세관·보안 | FCT-R06 | 자격 축의 내부자 |
| 위조부품 브로커 | FCT-R06 | 자격 축의 우회로 |
| 합법세력 고용 용병 | FCT-R06 | **해적과 별개** — 고용주가 있고 계약이 있다 |
| 밀수업자·항로가문 | 교역 §10 | 통행 축의 생존자 |
| 규칙을 구부리는 합법 사업체 | 교역 §10 | 회색 행위의 최대 수행자 |
| 의료·신분 중개인 | 교역 §10 | 부채 축 — 살리면서 착취한다 |
| 정치 세포 | 교역 §10 | 기억 축 |
| 포식적 인신매매 | 교역 §10 | 도덕적 하한선 |

**해적은 이 표의 한 줄이 아니다.** 위 유형 중 어느 것이든 자기 축에서 밀려나면 해적이 된다 — 통행을 잃은 항로가문, 계약이 끊긴 용병단, 배급이 막힌 인양조. 그래서 해적은 여럿이고 서로 다르며, 각자 **원래 무엇이었는지가 다르다.**

교역 바이블 §10의 서사 규칙을 그대로 승계한다.

> gray systems may save people and exploit them simultaneously

## 5. 서약낭인(F)의 위치 조정

라운드 2 레드팀은 F를 유일한 통과안으로 판정했다. 근거는 후반 의미가 정본([[grand-act-office-and-succession-state-table-v1]] 계열의 공동전단헌장 조항 4·8·12)에 직접 걸려 있고 인용이 전부 실재로 확인됐다는 것이다.

그 판정은 유지하되 **위치를 바꾼다.** F는 "클래스 7 전체"가 아니라 **독자가 이 계층에서 처음 만나는 구체적 집단 하나**다. 표본이지 대표가 아니다.

- 결속 원리: 목격 — 해산된 부대의 서약을 산 사람의 기억이 지탱한다
- 상실 조건: 목격자가 모두 죽어 서약이 검증 불가능해지면 유족 명부만 남고 해적이 된다
- 이식: 라운드 2 시안 E의 물리적 희소성(표류 앵커·제한 창·재측량 불가한 몸의 판단)을 F에 옮긴다. F의 자산이 기억뿐이면 희소성이 없다는 레드팀 지적에 대한 처방이다
- 폐기: 시안 G는 세력으로 쓰지 않는다. GA1 장면 하나만 FCT-R05로 이관한다

## 6. 기체 슬롯에 미치는 영향

[[frame-lineup-faction-coverage-gap-2026-08-13]]이 기록한 결손과 직접 연결된다. 현재 라인업 28건은 채택안 B의 밴드(32–40)에 4건 미달이고, 클래스 7·9·10에 슬롯이 0건이다.

이 문서의 구조를 채택하면 슬롯 산출 방식이 달라진다. **"용병 세력의 기체"를 한 벌 만드는 것이 아니라, 축별 행위자가 실제로 운용하는 기체를 도출한다** — 인양업자의 인양기, 항로가문의 통행기, 낭인단의 예인·크래들, 갈취조의 개조 습격정. 이들은 성격도 정비 생태계도 서로 다르며, §16-10 계수 규칙을 각각 따로 통과해야 한다.

슬롯 수 추정은 축과 행위자 유형이 확정된 뒤에만 산출한다. **지금 4건을 임의로 채우지 않는다.**

## 7. 아직 안 된 것 (승인 전 필수)

라운드 1 레드팀의 must_fix 12항 중 다음이 미해결이다.

1. **헬릭스(FCT-03) 경계선 대조표** — 신설 계층이 하지 않는 것(자본 공급 / 인증 발급 / 보험 인수 / 청구 보유 / 표준 제정) 목록을 Identity 절에 못박아야 한다. 이 표 없이는 승격 불가
2. **나포 6조건 유지 증명** — 크래들·키·부품·승조원·법적 엄호·수송 중 상품화되지 않는 조건이 최소 4개 남는지 검산
3. **E905 인과 순서 복원** — 감소의 원인은 "일정정보 파편화 제거 + 수리 접근 차단"이며 공통 자격증명 담보조건화는 결과다. 214→61, 47→11 등을 실제 약탈망에 1:1 지정한 표 필요
4. **인명 전면 재발행** — 세이(`Orvan Sei` 충돌), 소린(`세린` 유사음), 예하, 오신, 훈세 폐기
5. **수요측 예산 배선** — 지불 주체 확정 전에는 상비 계약단 규모를 문서에 기재하지 않는다
6. **Human Face 정원** — 영웅 3+ / 실무자 3+ / 피해자 2+ / 수혜자 2+ / 내부 비판자 2+ / 이름 있는 악행 실행자 / 선의로 해를 끼치는 인물
7. **ID 결정** — FCT-06 신설 vs FCT-R06 확장. 결정 후 관계행렬 6×6, 컬렉션 레지스트리 행, 엔티티 노트까지 일괄 파급
8. **GA1 접점** — "Ring C 종이 한 장"을 넘어 생도가 실제로 지불하거나 거절하는 선택으로 재설계

# 세린 오르 / Serin Or

> **링크 허브.** 설정을 여기 쓰지 않는다. 정본은 아래 링크가 보유하며, 이 노트는 요약과 링크만 유지한다 (`CLAUDE.md` §3, [[docs/_entities/README]]).

일상 호칭 `세린`. `확인`, `증언`, `추정`, `공식기록`, `현재 효력`을 엄격히 구별해 말한다. 누가 그 기록을 만들었고 누가 그것을 고칠 수 없는지를 묻는다. 유머는 정확한 표현과 모순에서 나온다. 해커식 만능도 아니고 감정 없는 사서도 아니며, 하나의 최종 진실을 선언하지 않는다.

# 하렌 도안 / Haren Doan

> **링크 허브.** 설정을 여기 쓰지 않는다. 정본은 아래 링크가 보유하며, 이 노트는 요약과 링크만 유지한다 (`CLAUDE.md` §3, [[README]]).

일상 호칭 `하렌`. 이상을 명단과 도착지 수용력과 의무로 바꿔 말하는 인물이다. "누가 먼저 가는가", "누가 계속 책임지는가", "도착한 뒤에는 무엇이 일어나는가"를 묻는다. 사람이 단위로 취급될 때 리안보다 노골적으로 화를 내지만, 정작 자신도 물류를 통해 같은 추상화를 저지를 수 있다. 후반 기록이 그에게 붙이는 `피의 제독`이라는 이름표는 그가 스스로 고른 것이 아니다.

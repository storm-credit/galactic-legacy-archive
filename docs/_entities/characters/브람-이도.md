# 브람 이도 / Bram Ido

> **링크 허브.** 설정을 여기 쓰지 않는다. 정본은 아래 링크가 보유하며, 이 노트는 요약과 링크만 유지한다 (`CLAUDE.md` §3, [[README]]).

이 구역의 숙련 도크 정비공이다. 개막 사고에서 제어판 대신 바닥을 보고, 스스로 굴러 오른발 발치의 수동 레버를 걷어차 기체를 멈춰 세운다. 사고 뒤에는 꺾인 지지대와 발목 핀에 걸린 하중을 읽어 현장을 안정화한다. 리안의 명령을 단순 수행하지 않으며, 미래의 정비 순서보다 현재 기체 상태에 맞는 판단을 한다. **비밀리에 전설적인 기술자나 요원이 아니다** — 평범한 사람이 결정적으로 기여한다는 증명(M-019)의 초기 사례다.

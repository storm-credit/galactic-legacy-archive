# 네라 비크 / Nera Vick

> **링크 허브.** 설정을 여기 쓰지 않는다. 정본은 아래 링크가 보유하며, 이 노트는 요약과 링크만 유지한다 (`CLAUDE.md` §3, [[README]]).

일상 호칭 `네라`. 변경 공방 출신 편입생으로 개막 시점에는 임시 정비평가를 기다리는 정비생이다. 물리적 고장, 시험 조건, 실제로 손을 댄 작업자를 근거로 말하며 부품이나 담당자를 특정하지 못하는 권위에 참을성이 없다. 근거 없는 정비공 직감은 스스로 금지한다. 지치면 농담하고 화가 나면 과도하게 정확해진다. 미래에는 리안의 변경 전선 전대에서 낡은 기체들을 되살리지만 공식 기록은 그 성과 대부분을 리안의 운용으로 돌리고 그녀에게는 실종 한 줄만 남긴다.

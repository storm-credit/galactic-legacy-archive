# 리안 칼데르 / Rian Calder

> **링크 허브.** 설정을 여기 쓰지 않는다. 정본은 아래 링크가 보유하며, 이 노트는 요약과 링크만 유지한다 (`CLAUDE.md` §3, [[README]]).

일상 호칭 `리안`. 제국 최후의 항로전에서 패배한 제독이 열일곱 살의 교정군사학원 입소생 몸으로 돌아왔다. 미래 기억은 전투의 항로와 시각을 분 단위로 보존하지만 그 곁에서 다친 한 사람의 이름은 남기지 않았을 만큼 불완전하고, 현재 기체의 부품 상태와도 어긋난다. 여러 결과를 말없이 계산한 뒤 짧게 결론만 내놓으며, 시간·거리·탄약·비용을 지불할 사람을 먼저 묻는다. 두려울 때는 지나치게 차분해지고 자신의 상태를 빠뜨린다. Archive는 그를 기록하지 않는다.

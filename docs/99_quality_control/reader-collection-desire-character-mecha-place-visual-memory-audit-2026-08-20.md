## 1. Executive Verdict

전체 수집·성장 시스템은 **DEEP / PASS FOR SYSTEM AUTHORITY**다.

그러나 분야별 완성도는 균등하지 않다.

- **서사·인과·비용·상실·계승**: 전 분야가 강하다.
- **기체의 실루엣/산업 디자인 문법**: 매우 강하다.
- **세력의 문화·공간·재료 문법**: 강하다.
- **핵심 캐릭터의 독자 즉시 식별용 외형 문법**: 부족하다.
- **파루스와 주요 함선의 외형/소리/생활감 기억 앵커**: 부분적이다.
- **아르디스 등 주요 장소의 사회·기능 설계**: 매우 강하나, 랜드마크·색·재료·소리·냄새·동선 같은 즉시 연상층은 상대적으로 약하다.
- **무기/유물/기술**: 기능·출처·비용은 강하나 독자 전면 아이콘은 선택적으로 더 필요하다.

따라서 현재 병목은 `more lore`가 아니다.

> **현재 병목 = reader-facing iconicity / collectible identity layer**

새 세계관, 새 세력, 새 기체 수를 늘리지 않는다. 이미 존재하는 FRONT급 대상만 골라 기억 가능성을 강화한다.

## 2. What “Collectible Desire” Means In This Project

《은하유산록》에서 수집은 물건을 창고에 넣는 행위가 아니다.

독자가 반복해서 느껴야 하는 욕구는:

1. **발견 욕구** — 저 사람/기체/배/장소가 무엇인지 알고 싶다.
2. **접촉 욕구** — 실제로 만나거나 타보고 들어가 보고 싶다.
3. **획득·관계 욕구** — 얻거나, 신뢰받거나, 운용권/통행권/자격을 얻고 싶다.
4. **조합 욕구** — 사람·기체·무장·함선·기술이 함께 작동하는 모습을 보고 싶다.
5. **변화 욕구** — 수리, 개장, 성장, 관계변화, 도시복구가 눈에 보여야 한다.
6. **상실 불안** — 파손, 이탈, 사망, 권리 상실, 도시 붕괴가 실제 가능해야 한다.
7. **완성 욕구** — 계보·사건·관계·문명의 빈칸을 채우고 싶다.
8. **계승 욕구** — 최종적으로 주인공 소유가 아니라 다음 사람/제도/지역에 무엇이 남는지 보고 싶다.

이 욕구를 강화한다고 사람·공동체·영토를 소유물화하지 않는다.

| I2 CMF / Material | 대표 색보다 재료·마모·표면·광택·작업흔적이 기억되는가? |

## 4. Domain-by-Domain Hostile Audit

### C1 Characters / Relationships

**Narrative depth: 5/5**

확인된 강점:
- 리안: external want / internal need / false belief / wound / competence / weakness / command flaw / relationship principle / voice / pilot style이 분리됨.
- 하렌: 현재 난민공동체·물류 습관·미래 Blood Admiral로의 부패 경로·독립 정치경로가 연결됨.
- 네라: 공방·부채·표준·정비·기술권리·독립조직 경로가 연결됨.
- 세린: 기록·출처·프라이버시·공개 책임·독립 검증기관 경로가 연결됨.
- 미아: 신체·구조·의료 중지권·동의·의료권력 부패 위험이 연결됨.
- 에른: 산업 구조 경험→구조/회수 전투문법→독립 해방정치→리안과 비종속 경쟁 관계가 연결됨.

**Reader-facing visual identity: 2/5 — GAP**

핵심 캐릭터 바이블은 목소리·습관·역할은 강하지만 다음을 일관된 정본 필드로 제공하지 않는다.

- 얼굴 실루엣/두상/헤어의 기억점;
- 키·체형보다 중요한 자세/무게중심;
- 손, 흉터, 의체, 작업흔적, 피부/머리 관리 같은 신체 생활감;
- 개인 소품 1개;
- 평상복/작업복/전투·임무복의 차이;
- 계급/기관 표식과 개인적 비순응의 차이;
- GA별 외형 변화와 누적 손상;
- 6인 동시 실루엣 비교 시 중복 방지.

**Risk:** 서사적으로는 서로 완전히 다른데 삽화/독자 머릿속에서는 모두 `군사학교 SF 청소년`로 평준화될 수 있다.

**Required correction:** 핵심 6인 + 에른 + 아우렐만 우선 `Character Collectible Identity Packet` 작성. 이름·사망·관계·능력을 바꾸지 않고 시각·생활 앵커만 제안한다. 최종 외형은 AUTHOR HOLD.

## 6. Collection-Desire Rhythm Across 1,100 Episodes

새 대상을 계속 추가하는 방식은 금지한다.

권장 reader-facing rhythm:

- 한 장면 주 수집목표: 1.
- 한 에피소드: 주 1 + 보조 1 이하.
- 한 소구간: 활성 3–5.
- 대액트 전면 도메인: 1–2 중심.
- 20~30화마다 반드시 `새 물건`이 아니라 다음 중 하나의 강한 변화 보상 1개:
  - 새 인물의 진짜 현재 욕망 공개;
  - 기존 기체의 새로운 임무구성;
  - 파손/복구/흉터 누적;
  - 새 함선이 아니라 기존 배의 새 공간 개방;
  - 무장/도구의 새 조합;
  - 유물 출처 뒤집기;
  - 세력과의 관계 단계 변화;
  - 장소의 접근권/서비스권 변화;
  - 미완성 세트의 의미 재해석.

중요:

## 10. Blind Spots Found

### B1 — Lore-depth illusion

문서가 길고 수치가 많다는 이유로 독자가 기억할 거라 착각할 위험.

### B2 — Mecha asymmetry

기체만 프랜차이즈급 시각 문법을 갖고 인물/도시가 기능문서에 머무르면 작품 인상이 `기체는 기억나는데 사람과 장소는 비슷함`으로 기울 수 있음.

### B3 — Catalogue inflation

415 source rows / 1,341 typed work records를 콘텐츠 수로 착각하면 독자에게 고유명사 폭탄이 됨.

### B4 — Upgrade addiction

수집욕을 새 상위기체/신무기로만 유지하면 07과 기존 자산의 정서적 가치가 죽음.

### B5 — Uniform cast syndrome

핵심인물의 서사 차이가 시각적으로 번역되지 않으면 앙상블의 강점이 표지/삽화/독자 기억에서 사라짐.

### B6 — Beautiful-but-uninhabited city

장소 컨셉아트를 멋진 우주도시로만 만들면 이미 설계된 노동·급여·식량·수리문화가 사라짐.

### B7 — Every-important-object-is-legendary

낡은 공구·작업표·식기·패치·임시표식처럼 평범한 물건이 관계를 기억시키는 역할도 필요. 단, 이를 전부 새 C4 유물로 승격하지 않는다.

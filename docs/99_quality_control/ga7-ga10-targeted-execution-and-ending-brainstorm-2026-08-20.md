# 2. GA7 — Rian / Haren Relational-War Surface

## Existing architecture that must not change

- Haren은 독립 route/logistics polity/authority를 가진다.
- Continuity corridor도 실제로 사람을 살린다.
- Haren의 D4는 실제 harmful choice다.
- Blood Admiral 전체 역사와 Haren 현재 책임은 동일하지 않다.
- Haren은 최종적으로 유죄·금지·배상 책임을 진다.
- 리안은 Haren의 재판관/주인이 아니다.

Problem:

> GA7가 충분히 깊지만, 원고 체감이 `항로위기 → D4 → 조사 → 재판`으로만 남으면 “친구였던 두 사람이 서로 다른 방식으로 사람을 살리려다가 갈라지는 전쟁”이 약해질 수 있다.

## Option A — Ideological Debate Front

Method:
- 둘이 여러 차례 직접 만나 중앙/분산, 항로파괴, 민간희생을 논쟁한다.

Strength:
- 주제 명확.

Failure:
- 말로 먼저 정답을 설명한다.
- D4가 논문의 사례처럼 보인다.

Verdict: **REJECT AS PRIMARY METHOD**.

## Option B — Military Duel Front

Method:
- 리안과 하렌이 각각 지휘하는 함대/기체가 직접 결전을 벌여 관계를 표현한다.

Strength:
- 감각적이고 즉시 이해됨.

Failure:
- Haren의 진짜 강점은 ace duel이 아니라 route/logistics/system control이다.
- 작품이 “둘 중 누가 더 센가”로 축소된다.

Verdict: **REJECT AS PRIMARY / SMALL TACTICAL CONTACT ALLOWED**.

## Option C — Competing Rescue Successes

Method:
- 같은 기간 서로 다른 전선에서 리안과 하렌 체계가 각각 실제 사람을 살린다.
- 리안 쪽의 군사 보호가 살린 사람과 Haren route priority가 살린 사람이 동시에 존재한다.
- 서로의 성공 때문에 상대의 자원/시간이 줄어드는 장면을 만든다.

Strength:
- 둘 다 옳을 수 있는 이유를 행동으로 보여준다.
- Haren constituency가 숫자가 아니라 사람으로 보인다.

Risk:
- 너무 평행구조가 되면 인물 직접 충돌이 약함.

Verdict: **STRONG**.

## Option D — Three-Mirror Relationship War

Method:

1. **공적 승부** — 서로 다른 체계가 같은 위기권에서 경쟁하며 둘 다 실제 성과를 낸다.
2. **대리 선택** — 리안의 사람/지역이 Haren 체계를, Haren의 사람/지역이 리안 지원을 합리적으로 선택하는 교차사례를 둔다.
3. **사적 균열** — D4 전, 둘이 상대의 능력을 인정하면서도 “이번엔 네가 틀리면 누가 죽는가”를 알고 헤어진다. 화해도 결별도 확정하지 않는다.

D4 이후:
- 사적 대화가 책임을 대신하지 않는다.
- 리안은 Haren을 구해 주거나 면죄하지 않는다.
- Haren은 “기록이 과장했다”를 자기 현재 선택의 변명으로 쓰지 않는다.

Strength:
- 전쟁, 정치, 우정, 독립성을 모두 살린다.
- Haren이 단순 피고인이 되지 않는다.

Risk:
- 새 장면을 억지로 추가하면 카드 호흡을 깨뜨릴 수 있음.

Verdict: **RECOMMENDED EXECUTION LENS**.

Implementation rule:
- 새 사건을 만드는 것보다 기존 convoy/route/denial/Continuity 장면에서 POV와 관계 비트를 재배치한다.
- exact scene-card changes require a later narrow mapping audit.

- lineage remains literally useful.
- no resurrection of peak combat asset.

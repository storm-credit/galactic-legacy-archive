Status: REVIEW — QC ONLY

## 1. Reader-Facing Anchor Triad

각 Grand Act는 새 아이템 수가 아니라 다음 세 종류의 **반복 인식 앵커**를 최소 하나씩 유지해야 한다.

### A. FACE

- 한 사람/집단의 현재 욕망과 선택.
- 주인공 소유물 아님.

### B. HAND / HARD ASSET

만지거나 타거나 고치거나 운반하거나 잃을 수 있는 것:
- 기체;
- 함선;
- 무장/공구;
- 물리 기록/키/매체;
- 생활/서비스 설비;
- 기존 장소의 물리 기능.

### C. PLACE / CONSEQUENCE

독자가 변화 전후를 기억할 공간·서비스 결과:
- 학교/도크;
- 배 내부;
- 도시 구역;
- 항로/노드;
- 피난 거점;
- Archive site;
- 병원/시장/공장/거주지 등.

한 축이 추상적이면 다른 두 축이 더 강해야 한다.

## 4. New-Item Quota Is Rejected

Do NOT require:
- one new hero per 20 episodes;
- one new mecha per block;
- one relic per GA;
- bigger flagship every act;
- higher rarity weapon every arc.

Instead require a `meaningful state change` every 20–30 episodes among existing front-stage assets.

Examples:
- tease → identity;
- access → use;
- use → scar;
- scar → repair with tradeoff;
- alliance → refusal;
- hull → home;
- route → obligation;
- evidence → reinterpretation;
- ownership → distributed custody.

## 5. Regression Checks For Every 20–30 Episode Window

At least four of six should be present across a window:

1. one FACE choice;
2. one tangible asset/place state change;
3. one cost/loss/refusal;
4. one synergy or operational use;
5. one future-record inversion/mystery step;
6. one larger-board unlock.

Failure warning:
- three consecutive windows where only legal/institutional status changes;
- three consecutive windows where reward is only more output/firepower;
- new proper nouns replacing old assets rather than deepening them;
- no old scar/relationship/ship/place returns for >50 episodes after being front-stage.

## 6. Prose/Context-Pack Rule

Context Pack should identify for each episode:

- `ACTIVE_DESIRE_MAIN` — one target;
- `ACTIVE_DESIRE_SECONDARY` — zero/one;
- `PHYSICAL_ANCHOR` — person/object/place readers can picture;
- `STATE_CHANGE` — what is different by episode end;
- `COST_OR_REFUSAL`;
- `REENTRY_ANCHOR` if returning after long absence.

This is an execution aid, not new canon.

## 7. Final Verdict

**Collection/progression engine across GA1–GA10: DEEP / PASS.**

Notable weakness is not missing content but **late-series tangibility risk** in GA4/7/8/9 and the current GA10 ending-detail mismatch.

Targeted fixes already sufficient:
- core-character visual identity;
- Parus visual/home identity;
- Ardis place memory;
- weapon/relic selective tactile anchors;
- ending reconciliation.

**Broad collection brainstorming: STOP.**

**Targeted reader-memory translation: CONTINUE.**

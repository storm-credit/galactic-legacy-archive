## 1. 목적

이 문서는 실제 원고를 `narration-harness-v1.md`, `prose-bible.md`, `revision-harness.md`, 현행 인물 voice lock에 대조해 **소리 내 읽을 때 발생하는 문제만** 한 파일에 누적 기록한다.

사건, 설정, 사망 여부, 관계, 숫자, 결말, 복선의 의미를 변경하지 않는다. v1 초안에 남은 구명·구표기는 역사적 초안 보존 규칙에 따라 그 자체를 현행 정본 위반으로 판정하지 않는다. 다만 실제 낭독 대상 본문/UI에 구명이 노출되면 낭독 준비 결함으로 기록한다.

**파일 운영 규칙:** 이 감사의 후속 낭독 검수도 새 버전 파일을 만들지 않고 이 파일에 계속 누적한다. 한줄 검수에서는 정상 줄을 전부 복제하지 않고, 실제 낭독에서 문제·잠금이 있는 줄만 원문 일부와 함께 기록한다.

## 2. 판정 기준

- **PASS**: 현행 낭독 하네스를 적용하면 즉시 읽어도 구조적 장애가 없다.
- **PATCH**: 국소 문장, 호흡, 표기 또는 낭독 지시를 보정하면 해결된다.
- **REWORK**: 기계음/UI 반복, 기록문 연속, 리듬 파편화 등으로 문단·장면 단위 정리가 필요하다.

판정은 **낭독 준비도**만 뜻한다. AUTHOR-APPROVED, 정본 승격, 공개·출판 승인을 뜻하지 않는다.

## 3. 전역 낭독 잠금

1. 리안 시점은 차분한 감각·판단 중심의 근접 3인칭을 유지한다. 해설자가 미래 의미를 알려주는 듯한 억양을 금지한다.
2. 기본 호흡은 중간 길이 문장이다. 충격·선택이 아닌 곳에서 짧은 문장을 연속 타격음처럼 읽지 않는다.
3. `[ ... ]` 시스템/Archive 출력은 감정 없는 기계음으로 읽되, 장면을 기계음이 지배하지 않게 한다.
4. 물리 표지·인쇄 문서는 시스템 음성으로 읽지 않는다.
5. 무전은 통제된 교신 톤, 전투·기동은 속도만 올리고 문장을 토막 내지 않는다.
6. 기관 문서·심문·기록은 평문과 구별되는 공식 톤을 사용한다.
7. `07호`는 **공칠호**로 읽는다.
8. 숫자는 한국어 자연 발음으로 읽는다. 거리·시간·각도·퍼센트는 빠른 장면에서도 흘리지 않는다.
9. 조기 복선 문장은 의미심장한 감속·저음·강조 없이 평문으로 읽는다.
10. 화자 잠금: 리안=비용·시간·거리·선택 / 하렌=사람·책임·도착 뒤 결과 / 네라=물리 실패·시험조건·손 / 세린=출처·증언·정정·현재효력 / 미아=몸 상태·동의·정지조건.

## 6. 교차 결함

### N1. v1 UI 과다
E007~E010, E018에서 가장 크다. 시스템 UI가 장면당 반복되면 낭독자가 아무리 잘 읽어도 인물 장면이 ‘기계 보고서 사이의 대화’처럼 들린다.

**권장:** 후속 원고 수정 시 `화면에서 실제로 읽어야 독자가 이해하는 핵심 출력`을 우선 남기고, 중복 상태값은 행동·반응·공식 기록 서술로 전환한다.

### N2. 복선 억양 스포일러
E002, E004, E006~E008, E011~E013, E018~E020에서 특히 주의한다.

**권장:** 키워드를 알고 있는 제작자가 ‘중요한 문장’처럼 읽지 않는다. 첫 독자가 아직 중요성을 모르는 수준의 평문 억양을 유지한다.

### N3. v1 구명
E006~E020의 v1 메타데이터에 구명이 남아 있는 것은 역사적 보존 범주다. 그러나 E009처럼 본문 UI에 노출되면 현행 낭독본으로 직접 충돌한다.

### N4. 화자 평준화 위험
- 리안: 비용/시간/거리/선택

## 8. 결론

E001~E005 v2는 **3 PASS / 2 PATCH / 0 REWORK**다. 첫 배치의 문장·UI 개정 효과가 실제 한줄 검수에서도 유지됐다.

현재 1~20화를 하나의 낭독 원고로 곧바로 사용하는 것은 권장하지 않는다. E001~E005는 현행 하네스 적용 조건으로 사용 가능하고, E006~E020은 아래 한줄 검수 항목을 후속 원고 수정 입력으로 사용한다.

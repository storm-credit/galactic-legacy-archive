# Pre-Writing Gate

Status: CANON
Owner Agent: A00 Novel PM Orchestrator
Last Reviewed: 2026-08-03
Depends On: All design bibles and harness documents
Used By: Decision to begin manuscript drafting
Open Risks: False confidence, unchecked placeholders, unresolved canon conflicts

## 1. Rule

본편 원고는 이 문서의 필수 항목이 모두 `PASS`가 되기 전에는 작성하지 않는다.

허용되는 예외:
- 문체와 시점 비교를 위한 1,000~2,000자 이하의 비정본 샘플
- 전투 전달 방식 검증용 짧은 실험 장면
- 대사 음성 검증용 비정본 대화

예외 샘플은 `experiments/`에만 저장하고 본편 정본으로 간주하지 않는다.

## 2. Scoring

- `PASS`: 정본 문서가 존재하고 교차검토 완료
- `PARTIAL`: 초안은 있으나 핵심 위험 또는 미결정 존재
- `FAIL`: 문서 없음, 중대 모순, 또는 사용처 불명
- `N/A`: 실제로 불필요하며 이유가 기록됨

집필 시작 조건:
- 모든 BLOCKER 항목 PASS
- 필수 항목 PASS 90% 이상
- PARTIAL 항목마다 완화책·담당자·해결 시점 존재
- S0 위험 0개
- S1 위험 3개 이하이며 첫 20화에 영향 없음

## 7. Characters & Factions

- [ ] 각 세력이 주인공 없이도 움직이는 목표와 계획을 가진다.
- [ ] 적대자가 합리적 승리 조건과 학습 능력을 가진다.

## 8. Story Architecture

- [ ] BLOCKER: 결말이 확정됐다.
- [ ] BLOCKER: 8~10개 대액트가 결말에서 역산됐다.
- [ ] BLOCKER: 각 대액트의 종료가 다음 대액트의 원인이 된다.
- [ ] 다음 300화가 액트 수준으로 설계됐다.
- [ ] 다음 100화가 서브액트 수준으로 설계됐다.
- [ ] 첫 20화가 회차 비트 수준으로 설계됐다.
- [ ] 첫 5화가 장면 카드 수준으로 설계됐다.
- [ ] 전투·정치·탐험·영입·미스터리의 반복 방지표가 있다.
- [ ] 전력 인플레이션 대신 책임·윤리·정보·규모가 함께 상승한다.

## 9. Mystery, MacGuffin & Ending Payoff

- [ ] BLOCKER: 회귀의 원인과 은하유산록의 정체가 확정됐다.
- [ ] BLOCKER: 핵심 맥거핀의 최초 암시부터 결말 사용까지 추적된다.
- [ ] BLOCKER: 최종 반전이 사전 단서 없이 성립하지 않는다.
- [ ] 주요 비밀마다 제시·오도·부분회수·최종회수 시점이 있다.
- [ ] 주인공이 알고 있는 역사와 실제 역사의 차이가 설계됐다.

- [ ] 결말 회수가 마지막 구간에 과도하게 몰리지 않는다.

## 11. Stress Tests

- [ ] BLOCKER: 치명적 설정 모순이 없다.
- [ ] BLOCKER: 첫 20화에서 세계관 설명이 사건을 압도하지 않는다.
- [ ] BLOCKER: 주인공의 미래 지식이 무제한 공략집이 아니다.
- [ ] 적이 무능해야만 성립하는 승리가 없다.
- [ ] 기체전과 함대전이 서로의 의미를 빼앗지 않는다.
- [ ] 수집품·영웅 수가 독자 기억 한계를 넘지 않도록 계층화됐다.
- [ ] 1000화 확장에서 같은 패턴 반복 위험이 검토됐다.
- [ ] 정치·경제·보급이 전쟁 결과에 반응한다.
- [ ] 윤리적 맹점과 사람의 도구화 문제가 작품 안에서 다뤄진다.
- [ ] 유사작과 핵심 사건 배열이 과도하게 겹치지 않는다.

## 12. Repository Integrity

- [ ] 모든 CANON 문서에 상태·담당·의존성·사용처가 있다.
- [ ] 중복 정본 문서가 없다.
- [ ] 폐기 설정은 DEPRECATED로 보존됐다.
- [ ] 결정 변경은 decision log에 기록됐다.
- [ ] 연표·용어·인물·장비 인덱스가 있다.
- [ ] 문서 링크가 깨지지 않았다.
- [ ] 미결정 사항과 가정이 숨겨져 있지 않다.

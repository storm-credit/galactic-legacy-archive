## 0. Purpose

Before exact GA10 ending remapping or final core-cast art direction, collect cross-media references from games, manga/anime and film to answer two separate questions:

1. **What structural effect is useful?**
2. **What resemblance risk must be actively rejected?**

This follows `CLAUDE.md` Phase 1: references are used for structure, effect and reader expectation only. No sentence, character, scene, reveal, costume set, face or iconic composition may be copied.

The user direction for this preflight is explicit:

> proceed with the recommended ending package, but first research and collect references so character faces and overall designs do not become too similar to existing game/comic/film/anime characters.

This document does **not** itself canonize the ending package or final appearance.

## 1. Collection Method — Store Links and Extracted Functions, Not Third-Party Art

Repository rule for reference collection:

- do **not** commit copyrighted screenshots, concept art, movie stills, model sheets or scans merely as a moodboard;
- store source title, medium, source URL, useful design/ending function, and explicit no-copy note;
- if a later visual board is needed, use licensed/officially permitted material only as off-repo viewing reference or generate original concept studies from abstracted constraints;
- no prompt may say `make Rian look like X`, `same face as X`, `same outfit as X`, or equivalent;
- a single named fictional character may contribute at most **one primary design lesson** to one original character direction;
- exact hairstyle + face proportions + costume silhouette + signature prop from one reference is a hard FAIL even if colors are changed.

### 1.1 Reference axes

References are separated into four axes so they cannot collapse into a clone:

1. **Readability axis** — silhouette, posture, motion, hierarchy of visual information.
2. **Material/institution axis** — how work, status and wear appear in clothing/equipment.
3. **Arc axis** — how appearance changes with responsibility, damage, distance or ordinary life.
4. **Ending-function axis** — how a long story proves aftermath, separation, loss and continuity.

No original character needs an external reference for every axis. Existing canon and internal identity remain the primary source.

## 4. What We Actually Borrow — Abstracted Rules

### 4.1 Character readability

Adopt:

- read a character at three distances: headshot, half-body, 64px full-body silhouette;
- posture/motion must carry at least one identity signal independent of color;
- job geometry must differ: what the hands do, where weight sits, what space the body protects or measures;
- face is allowed to be appealing but should not converge on one generic `pretty anime face` template.

Do not adopt:

- any reference franchise's exaggeration ratio;
- one-to-one facial landmarks;
- faction palettes as copied palettes;
- reference character's signature prop as substitute for personality.

### 4.2 Face differentiation — production test, not canon lock

Before author-final character art, compare the core cast in four neutral studies:

1. **Hair-off grayscale head test** — remove color and hairstyle dominance; check head shape, jaw, cheek, brow, nose/eye spacing and age/read.
2. **Same-light neutral-expression test** — everyone under the same lighting/expression; if identity collapses, FAIL.
3. **Uniform-normalized test** — place academy-era characters in the same institutional base layer; face/posture must still separate them.
4. **Props-off silhouette test** — remove bags/tools/weapons; body stance and motion tendency must still separate at least the primary cast.

These are production diagnostics only. They do not create exact canon anatomy.

### 4.3 The `three-source firewall`

For any final character-sheet direction:

- Source A may inform **readability**;
- Source B may inform **material/occupation**;
- Source C may inform **arc/ending wear**;
- internal canon supplies biography, relationship, injury, authority and exact story state.

No external source may supply two of `face + hair + costume + signature prop + relationship dynamic` for the same original character.

### 4.4 Mecha/ship differentiation

Adopt:

- silhouette before micro-detail;
- function creates memorable negative space;
- scars/repairs should show history, not cosmetic `battle damage skin`;
- symbolic motif remains subordinate to engineering.

For Parus specifically, existing `A structural silhouette + C progression void + D scar language` remains stronger than copying any famous spaceship.

## 6. High-Risk Reference Families — Use as Collision Checks, Not Design Sources

The following are close enough to this project's genre surface that they should mainly be used to ask `are we accidentally resembling this?`, not to supply direct design ingredients:

- major Gundam protagonist/rival face-and-suit pairings;
- Legend of the Galactic Heroes command-uniform and admiral tableau vocabulary;
- Star Wars throne/medal/legacy imagery;
- iconic crew-home ships such as Millennium Falcon / Bebop / Rocinante;
- cyberpunk neon-hacker visual shorthand;
- generic black-long-coat military genius archetype.

A similarity match is not automatically a problem at one axis. It becomes a red flag when **three or more salient axes** converge: face/head, hair, silhouette, palette/material, signature prop, posture, relationship framing, or iconic scene composition.

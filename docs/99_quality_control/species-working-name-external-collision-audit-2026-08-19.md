## 1. Method

A quick public-web collision screen was run for the seven NONCANON working labels.

Screening priorities:
1. exact species/civilization name in SF or space opera;
2. exact name used by an alien/nonhuman character with similar biological concept;
3. major/current Korean fiction title collision;
4. recognizable game/fantasy character collision;
5. ordinary brand/person/acronym use.

This is a **creative-distance / reader-confusion screen**, not legal advice or trademark clearance.

## 3. Load-Bearing Sources Consulted

### Braxi
- Astra Publishing House, *In Conquest Born* description: explicitly describes “Braxi and Azea” as interstellar civilizations.
- Michael Whelan / publication art page for the same novel confirms the Braxi/Azea terminology.

Result:
- direct same-genre collision;
- not acceptable as final species label.

### Numar
- *Urban Rivals* reference material: Numar is connected to the amphibian people of Aquanis.
- public SF/fantasy review of *The Green Man* describes a nonhuman named Numar.

Result:
- our working Numar is also amphibious/fluid-supported, making this more than a random phonetic collision.

### Verin
- *The Nature of Predators* species glossary/reference material uses Verin as a species name.
- Star Trek reference material uses Verin as a named alien leader.

Result:
- exact species-name collision in contemporary SF ecosystem;
- replace.

### Tesar
- public fan-setting reference uses Tesar as a sentient reptilian race;
- Might and Magic reference uses Tesar as a character name.

Result:
- not major-commercial species collision at Braxi/Verin level, but easy to avoid now.

### Kelik
- Fire Emblem fan-game reference material identifies Kelik as a major/recognizable character in *The Last Promise*.

Result:
- not a species collision, but name is already strongly fantasy/game-coded in a niche audience.

### Seia
- public SF fan setting uses `Seia System`;
- Tapas 2026 series `Seian / 세이안` is phonetically close for Korean readers.

Result:
- exact label is not yet a high-risk species collision, but Korean-reader confusion deserves rescreen before promotion.

### Ivra
- Magic lore has `Ivra Jursdotter` as a character;
- IVRA also appears as unrelated modern brand/research naming.

Result:
- generic personal/acronym collision only; no same-concept species collision found in this quick screen.

## 5. Replacement Name Design Rule

Replacement names should be generated from the existing naming grammar, then pass three stages:

1. **internal repository collision**;
2. **external fiction/game/SF collision**;
3. **Korean pronunciation/active-window collision** with Rian/Haren/Nera/Serin/Mia/Ern and major faction/mecha terms.

Do not optimize for “alien sounding.” Optimize for:
- short recall;
- pronunciation;
- category separation;
- low genre collision;
- no obvious biology stereotype encoded in the word.

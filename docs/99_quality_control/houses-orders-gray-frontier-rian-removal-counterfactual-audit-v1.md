## 0. Audit question

The current proposal architecture gives houses, orders, mercenaries and local forces believable institutional forms.

The stronger question is:

> **Would they still make consequential choices if Rian disappeared for the next ten episodes?**

This audit does not ask whether they have lore.
It asks whether they have **causal independence**.

Required for any recurring named organization before front-stage promotion:

1. objective independent of Rian;
2. current clock/deadline independent of Rian;
3. resources and liabilities it controls itself;
4. at least two internally credible options;
5. a decision that can be made while Rian is absent;
6. a cost paid before Rian can respond;
7. a changed state Rian later encounters rather than creates.

# 1. House layer

## HSE-A — Founding Covenant House

### Ten-episode Rian-removal test

Independent objective:
- preserve or reinterpret one founding-law privilege/obligation during succession uncertainty.

Clock:
- registry/hearing deadline;
- trust distribution date;
- claimant recognition window;
- archive disclosure deadline.

Resources:
- old archives;
- ceremony/legal standing;
- land/trust income;
- patronage contacts.

Independent choices:
1. endorse one legal interpretation;
2. remain neutral and release evidence;
3. support a temporary compact while withholding sovereign recognition;
4. split internally by branch.

Costs without Rian:
- loss of court access;
- trust freeze;
- branch defection;
- public legitimacy damage.

Changed state Rian later encounters:
- evidence already public;
- coalition already shifted;
- branch already defected;
- old privilege already challenged in court.

Verdict:
- **PASS — high autonomy potential.**

Satellite risk:
- FAIL if the house exists only to tell Rian which claimant is legitimate.

## HSE-B — Military-Service House

Independent objective:
- preserve service reputation, officer network and dependents while deciding whether a disputed command is lawful.

Clock:
- deployment order;
- reserve recall;
- officer confirmation;
- casualty/dependent-payment deadline.

Resources:
- officer/veteran network;
- academy ties;
- service foundations;
- political reputation.

Choices:

- retain provincial duty;
- split by serving branch;
- fund dependents while refusing political endorsement.

Cost:
- command careers;
- pension/foundation exposure;
- accusations of treason/disloyalty;
- internal family split.

Verdict:
- **PASS IF service duty outranks protagonist relationship.**

Stop condition:
- reject if “famous ace family joins Rian because he proves himself.”

## House portfolio result

All six functional archetypes can pass protagonist-removal structurally.

But named-house promotion must include a **Current Autonomous Plan** field.

Required fields:

```text
Current objective:
Current deadline:
Current resource at risk:
Current internal split:
What happens if Rian never contacts them:
What state Rian encounters later:
```

Without these, a house remains background lore.

# 2. Knight / service-order layer

## K-01 Route Shield Order

Rian absent:
- convoy still departs;
- distress call still arrives;
- corridor service obligation still triggers;
- merchant/toll dispute still exists.

Autonomous hard choice:
- abandon profitable convoy to answer mandatory rescue, or violate charter.

Possible state change before Rian arrives:
- rescue succeeds but depot fuel reserve collapses;
- convoy clients sue;
- corridor becomes underprotected.

Verdict:
- **VERY STRONG PASS.**

---

## K-02 Bastion / Node Custodian Order

Rian absent:
- node attack/thermal instability/denial order still progresses.

Autonomous hard choice:
- obey military denial order versus invoke technical/civilian stop authority.

Possible result:
- order refuses destruction, loses officers or becomes politically suspect while preserving evacuation infrastructure.

Verdict:
- **VERY STRONG PASS.**

Risk:
- must not exist merely so a cool knight can duel Rian.

---

## K-03 Witness / Custody Order

Rian absent:
- witness/prisoner/medical evacuee still must cross jurisdictions.

Autonomous hard choice:
- protect an unpopular claimant/witness against the very faction funding escort.

Cost:
- funding;
- passage rights;
- casualties;
- accusations of political bias.

Verdict:
- **VERY STRONG PASS.**

This order can create plot consequences before Rian knows the protected person exists.

---

## K-04 Expeditionary Service Order

Rian absent:
- frontier settlement still faces infrastructure expiry and governance handoff.

Autonomous hard choice:
- extend emergency mission and risk becoming unelected ruler versus leave on charter date and risk collapse.

Cost:
- local legitimacy;
- casualties;
- dependency;
- patron funding.

Verdict:
- **VERY STRONG PASS.**

## Order-layer anti-satellite rule

A named order must have at least one current obligation that:
- began before contact with Rian;
- will expire/fail whether or not he arrives;
- can put the order in conflict with its own patron.

If its only current mission is `help/stop/follow Rian`, reject or downgrade it.

# 5. Cross-layer collisions that create real parallel stories

The strongest multi-front structure does not isolate these organizations.

Use collisions such as:

### C-01 House × Order
- patron house demands political deployment;
- order charter requires rescue elsewhere.

### C-02 House × Provincial Defense
- political family backs central claimant;
- province refuses redeployment because local route is threatened.

### C-03 Yard House × Mercenary Company
- company cannot pay repair invoice;
- house yard impounds frames before a new emergency contract.

### C-04 Order × Smuggler Network
- custody order lawfully blocks a route used to move medicine/refugees.

### C-05 Garrison × Node Custodian
- garrison receives denial command;
- custodian order invokes technical stop.

### C-06 Civic Militia × Contract Security
- wealthy district pays private defense;
- militia must choose whether to redirect scarce rescue assets to unprotected neighborhoods.

### C-07 Archive House × Witness Order
- archive family claims privacy/title;
- custody order holds evidence under public/legal mandate.

Each collision can advance while Rian is on a completely different front.

# 6. Mandatory “offscreen state delta” for recurring organizations

For every recurring named organization, once per major act where it is active, track at least one state delta that can occur without Rian present:

Possible deltas:
- officeholder changes;
- debt increases;
- client defaults;
- contract expires;
- branch secedes;
- strike begins/ends;
- convoy lost/saved;
- repair completes/fails;
- charter renewed/revoked;
- member refuses order;
- local election changes mandate;
- trust asset frozen/released;
- route closes/reopens;
- patron withdraws funding.

This is not a POV quota.
The event may be learned later through:
- report;
- changed personnel;
- empty berth;
- new contract terms;
- damaged machine;
- altered vote;
- debt notice;
- funeral;
- absence.

# 7. Reader-load control

Do not dramatize every autonomous clock.

Recommended per subact:
- 2–4 active causal clocks author-side;
- normally 1 protagonist/mission clock;
- 1 ally/local/institutional clock;
- 1 antagonist/competitor clock;
- optional 1 civilian/economic/family clock.

Only switch POV where the choice/cost would be distorted if told later.

This preserves Rian as the primary protagonist while keeping the galaxy alive.

House architecture:
- **PASS WITH CURRENT-PLAN FIELD REQUIRED**.

Knight/service-order architecture:
- **VERY STRONG PASS**.

Gray-layer architecture:
- **VERY STRONG PASS IF ECONOMICS/CONTRACTS REMAIN ACTIVE**.

Frontier-defense architecture:
- **VERY STRONG PASS IF LEGAL CHAINS AND HOME OBLIGATIONS REMAIN SEPARATE**.

Series-fit verdict:

> **PASS — these middle-layer organizations can support genuine protagonist-absent story movement without creating new grand acts.**

Main regression risk:

> turning a rich institution into “the house/order/company that likes or hates Rian.”

Control:

> **No recurring organization is front-stage ready until it can lose money, power, people, time or legitimacy through a decision Rian did not cause and may not witness.**

Canon / scene-card / manuscript changes: **NONE**.

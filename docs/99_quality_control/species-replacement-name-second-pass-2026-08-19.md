## 1. Why a second pass was run

The first seven working aliases were created as internal design handles. External screening found direct or semantically close collisions for several names, so a replacement candidate pool was generated and screened again.

The goal of this second pass was not to find a legally unique invented word. It was to avoid:
- recognizable same-genre species/civilization reuse;
- strong game/fantasy proper-name collisions;
- current brand/service names likely to dominate search results;
- accidental offensive/awkward ordinary-language meanings;
- internal repository collisions.

## 2. Candidate pool tested

First replacement pool included:
- Tovren / Kavru / Berval
- Osern / Avelun / Tovel
- Kairik / Kervi / Zeren
- Vesar / Sovel / Aderun
- Luvei / Esari / Neyal
- Ireva / Omrel / Savri

Internal repository grouped search found no exact collisions for the tested candidates.

External exact-string screening then exposed multiple non-fictional and fictional collisions.

## 3. Second-pass findings

### Strong avoid

- `Tovren` — active AI/technology publication/service name in 2026, plus fictional character use.
- `Tovel` — active enterprise-AI governance product/company name in 2026.
- `Kervi` — exact registered trademark use plus commercial name use.
- `Aderun` — existing fantasy/RPG NPC/name use.
- `Kavor` — Warframe faction/group name and active engineering company; rejected during alternate testing.
- `Varuk` — Magic: The Gathering character and other game/fantasy uses; rejected during alternate testing.
- `Elyun` — recognizable existing fantasy/anime character name.
- `Oriva` — active collaboration/AI-app product names.
- `Saevi` — active artist name and Latin lexical form.

### Medium / ordinary-name noise

- `Kavru` — modern military-medical acronym/unit name; avoid because this project also uses military medicine.
- `Esari` — ordinary-language/personal-name collisions and undesirable lexical associations.
- `Avelun` — current commercial/platform naming.
- `Luvei` — explicitly marketed as a brandable domain/name.
- `Neyal` — existing surname/first-name and fan/RPG character use.
- `Ireva` — active brand/studio spelling exists; no direct same-genre species collision found, but not clean enough to promote.
- `Berval` — active artist name; low direct genre risk but not compelling enough to force adoption.

### Comparatively clean but not author-ready

- `Osern` — no significant same-genre collision surfaced in the quick screen; mostly incidental username/anagram noise.

Even here, “no result found” is not proof of uniqueness.

## 4. Red-Team Decision

Do **not** force a seven-name migration merely because a candidate survived one search pass.

Reason:
- biology, ordinary life, infrastructure and story use already have stable slot IDs;
- repeated alias churn creates more continuity risk than value;
- final species names are high-salience reader-facing IP assets and deserve a dedicated aesthetic + collision pass;
- one clean name among seven does not justify partial migration.

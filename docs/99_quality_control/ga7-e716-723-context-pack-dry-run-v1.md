## 5. Red-Team Against Overcorrection

### Attack A — invent one recurring investigator to humanize all eight episodes

**REJECT.**
The cards support investigator roles and existing witnesses/operators but do not require a new named focal. A new named analyst would be template-driven canon creation.

### Attack B — turn the 212-document corpus into one physical master archive box

**REJECT.**
This would falsely centralize distributed custody/evidence and make an object symbolize authority it does not possess.

### Attack C — use Haren in every episode as FACE

**REJECT.**
Haren is a current subject/actor, not the sole answer. Doing so would recreate the exact one-person bias the arc is dismantling.

### Attack D — add a victim vignette for each omission category in E722

**REJECT.**
The merged carrier rule explicitly prefers existing affected actors/route-service harms. New case-of-week victims inflate canon and fragment reader memory.

### Attack E — make E723’s 29 strong matches a culprit scoreboard

**REJECT.**
Red-team arithmetic says 29/41/27 are comparison classes, not guilt or perpetrator counts.

### Attack F — make the authority graph or provenance mirror a magical truth machine

**REJECT.**
They organize evidence; they do not supply intent, guilt, complete authority or hidden-master attribution.

## 6. What the Dry-Run Revealed About the Schema

### PASS

1. The six common fields are sufficient to translate all 8 episodes without changing cards.
2. HIGH-WATCH additions successfully preserve recurring FACE/ASSET/PLACE and agency boundaries.
3. `STATE_CHANGE`, `COST_OR_REFUSAL`, `REENTRY_ANCHOR` absorb the prior duplicate DELTA/COST/REENTRY vocabularies cleanly.
4. `CURRENT_OWNER_OF_DECISION` is especially valuable in GA7 because the entire arc distinguishes model, key, signer, office, assembly and implementation authority.
5. `RIAN_CANNOT_OVERRIDE` prevents the protagonist-centered lens from turning into causal/epistemic ownership.
6. Allowing `UNRESOLVED FROM APPROVED SOURCES` prevents template completion from inventing rooms, clerks, victims or exact object IDs.

### Remaining limitation

The schema does not by itself choose the final prose focal person or exact physical location when the card only specifies role/custody/function. That is correct behavior. At actual manuscript-production time, the Context Pack must search current cast/custody/location sources and either:

- reuse an already-existing compatible focal/place;
- keep an unnamed existing role where prose permits;
- or stop under normal canon naming/change control if an exact new identity is genuinely required.

It must **not** solve the blank by inventing.

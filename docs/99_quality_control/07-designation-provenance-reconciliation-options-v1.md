## 0. Problem

Current accepted/working documents use three identifiers around the same reader-facing `07호`.

### First-frame bible

- school designation: `CTF-13/07`;
- hidden original lineage: `AUXILIA-0`;
- AUXILIA described as lattice inspection / rescue / exterior repair / control-key transport ancestry.

### Opening operational state

- formal registry: `AUX-07 다목적 상호운용 훈련 프레임`;
- everyday name: `07호`;
- original design intent: civil/emergency interoperability trainer and utility frame later militarized.

### New author direction

- `07` should be understood as one historically important prototype/demonstrator number among a larger `01–17/20` experimental family;
- not every numbered article succeeded;
- successful/partial articles seeded later frame lineages.

These three layers must not be silently flattened into one code.

---

# 1. Reconciliation principles

Any acceptable solution must preserve:

1. `07호` as the stable reader-facing everyday name;
2. existing school use of `CTF-13/07`;
3. existing current registry use of `AUX-07`;
4. existing AUXILIA service/intervention ancestry;
5. service-first, later-militarized history;
6. 07 is not strongest weapon or universal ancestor;
7. broad service access is not sovereign authority;
8. no requirement that all 01–20 survive;
9. no AXIOM universal-origin retcon;
10. Archive may misclassify history without inventing events from nothing.

# 2. Option A — Three names, no historical slot identity

Structure:

```text
AUXILIA-0 = old technical lineage/program
AUX-07 = later administrative model/registry
CTF-13/07 = Academy local asset designation
```

The `07` in current names is not necessarily the old umbrella prototype slot.

### Strength
- smallest continuity intervention;
- all current documents can be read literally.

### Weakness
- weak fit with author direction that `07` itself belongs to the remembered numbered demonstrator family;
- creates two different “07” ideas if a separate historical P-07 later exists.

### Verdict
**CONTINUITY-SAFE BUT AUTHOR-INTENT WEAK.**

# 3. Option B — Historical Slot 07 + AUXILIA technical lineage + later re-registration

Structure:

```text
[Umbrella numbered experimental authorization — name HOLD]
               │
          Historical Slot 07
               │
     AUXILIA-0 service/intervention
       demonstrator architecture
               │
     rebuilds / transfers / stripping
               │
      AUX-07 administrative registry
               │
       CTF-13/07 Academy asset code
               │
              07호
```

Interpretation:
- `07` is the historically persistent demonstrator-slot identity;
- `AUXILIA-0` is the old service/intervention technical program/family/article architecture associated with that slot;
- later authorities keep or rediscover `07` while changing category and legal title;
- `AUX-07` is a later civil/training administrative registry form;
- `CTF-13/07` is the Academy’s local inventory/use classification.

### Important limit

This does **not** require the current school hull to contain 100% of the original Prototype 07 metal.

The lineage may be Ship-of-Theseus-like:
- original core/structure fragments;
- later replacement limbs;
- training reactor;
- military trainer parts;
- preserved service grammar;
- disputed registration.

Identity is carried by a combination of:
- service architecture;
- provenance;
- custody history;
- surviving core/components;
- later administrative continuity.

### Strengths

- strongest fit with author’s new numbered-prototype intent;
- preserves all three existing identifiers instead of deleting one;
- explains why “07” survives across centuries/administrations;
- supports Archive confusion between prototype number, wartime frame and Academy asset;
- fits the series theme that identity is not one serial plate.

### Risks

- exact relationship between `AUXILIA-0` and umbrella slot 07 must be phrased carefully;
- readers could assume `-0` means Prototype 0 unless naming grammar is later explained;
- making 07 the only surviving numbered identity can over-centralize mystery if other relevant slots never matter.

### Control

`AUXILIA-0` should not be defined as “Prototype Zero” by default.
It can be:
- technical generation mark;
- demonstration architecture designation;
- workstream nomenclature;
- prestandard family label.

Exact semantics remain HOLD.

### Verdict
**RECOMMENDED IF NUMBERED-PROTOTYPE DIRECTION IS AUTHOR-APPROVED.**

# 8. Archive-error model under Option B

Archive may encounter:
- `07` repeated across old authorization records;
- wartime action reports;
- royal/Imperial custody chains;
- service-key histories;
- later Academy registration.

A category-optimized historical summary can wrongly output:
- “royal prototype combat frame 07”;
- “one of seven sister frames”;
- “exclusive strategic key carrier.”

Correction later:
- Slot 07 was a service/intervention lineage whose wartime/custody history created combat/royal associations.

This preserves Archive fallibility as classification error rather than random falsehood.

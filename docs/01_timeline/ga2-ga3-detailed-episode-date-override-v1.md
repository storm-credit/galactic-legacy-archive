## 1. Reason for Correction

The master chronology locks:
- GA2 E101–210: `CY 742-08-01 → CY 743-03-31`;
- GA3 E211–330: `CY 743-04-01 → CY 743-09-30`.

Several detailed-production documents retained earlier draft dates outside those envelopes. The events, sequence, counts, recovery durations, authority states and causal relationships remain valid; only conflicting absolute calendar labels are noncanonical.

## 2. Authority Rule

1. This file is the authoritative absolute episode-date table for E101–330.
2. If a detailed card or state sheet has another absolute date, replace it mentally and operationally with the date below.
3. Relative durations remain unchanged unless an explicit later correction states otherwise:
   - hours/minutes inside an operation;
   - 9–14 day closures;
   - 18–30 day housing loss;
   - 21-day facility agreement;
   - 72-hour compact;
   - 7–12 month injury limit;
   - 10–24 month T-19 reoccupation limit.
4. When an episode contains scenes spanning more than one day, the listed date is the episode’s canonical opening date; scenes may continue until before the next episode’s opening date.
5. E311–330 detailed cards must use this table directly and must not repeat the superseded draft calendar.
6. This correction does not change episode order, act/subact structure, ages, licences, deaths, cargo, force readiness or institutional outcomes.

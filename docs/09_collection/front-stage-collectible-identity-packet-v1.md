# Front-Stage Collectible Identity Packet v1

Status: PROPOSED — NONCANON
Canon Promotion: NOT AUTHORIZED
Publication: NOT AUTHORIZED
Purpose: 이미 존재하는 FRONT급 인물·기체·함선·무장·유물·기술·세력·장소를 새 설정으로 재창조하지 않고, 독자가 기억하고 재등장을 기다릴 수 있도록 최소 reader-facing identity를 정리하는 재사용 패킷.

## 1. Governing Rule

이 패킷은 정본 사실을 만들지 않는다.

- 사건, 능력, 사망, 관계, 권한, 수치 변경 금지.
- 상위 정본의 기능/배경/손실을 시각·감각·행동 언어로 번역한다.
- 최종 외형/아트 선택은 AUTHOR HOLD.
- `멋있다`보다 `왜 이렇게 생겼고 어떻게 살아 쓰이는가`가 우선이다.
- FRONT급 대상만 작성한다. 모든 등록 항목을 시트화하지 않는다.

## 2. Universal Header

| Field | Required content |
|---|---|
| Stable subject | 현재 정본 ID/이름 또는 proposal slot |
| Canon tier | WC/AS/FR/DD/PROPOSED/HOLD 등 현재 유효 상태 |
| First reader-facing window | 실제 첫 노출 회차/GA |
| Primary desire | 발견 / 관계 / 획득 / 운용 / 조합 / 완성 / 계승 중 중심 1~2개 |
| One-line recall | 수백 화 뒤에도 기억시킬 한 문장. 새 정본 사실 금지 |
| Story promise | 독자가 이 대상에 대해 더 알고 싶어야 하는 질문 |
| Hard veto | 절대 바꾸면 안 되는 정본/테마 요소 |

## 3. Twelve Identity Axes

### I1 Shape / Silhouette

- 인물: 자세, 어깨/목/손 사용, 보행, 장비를 포함한 전체 윤곽.
- 기체/함선: 64~128px에서 구분되는 큰 질량.
- 장소: 원거리 구조와 이동축.
- 유물/무장: 손에 든 크기와 방향성.

### I2 Material / Surface

- 재료 2~3개.
- 어디가 새것이고 어디가 닳는가.
- 누가 정비/세탁/수리하는가.
- 색은 재료/기관/생활에서 파생한다.

### I3 Motion / Habit

- 정지 포즈보다 반복 행동 하나.
- 움직임은 직업과 상처/제약을 반영한다.

### I4 Sensory Anchor

다음 중 1~2개만 강하게:
- 소리;
- 진동;
- 온도;
- 냄새;
- 표면감;
- 조명/그림자 변화.

### I5 Story Promise

처음 노출에서 답하지 않는 질문 하나.

좋은 예:
- 왜 이 정비사는 자기 공구가 하나도 없는가?
- 왜 이 배의 두 번째 격납고는 생활공간으로 쓰이는가?
- 왜 이 도시의 공식 추모판과 노동자 추모판 이름 수가 다른가?

### I6 Barrier

- 법적;
- 기술적;
- 관계적;
- 윤리적;
- 물류적;
- 신체적.

무료 획득 금지.

### I7 Cost / Maintenance

얻은 뒤 더 중요한 비용.

- 사람: 신뢰, 시간, 반대, 이탈.
- 기체/함선: 정비, 열, 부품, 인증, 승무원.
- 장소: 서비스, 방위, 시민권, 유지비.
- 유물: 보관, 공개, 반환, 정치책임.

### I8 Synergy

`A + B = C`가 아니라 서로 다른 veto/한계가 충돌하며 새 가능성을 만드는 조합.

### I9 Refusal / Counter

대상 또는 세계가 주인공에게 `아니오`라고 말할 수 있어야 한다.

### I10 Scar / Evolution

외형/행동/공간에 누적되는 변화.

- 복구하면 완전히 새것이 되지 않는다.
- 상실 장부를 지우지 않는다.
- 독자는 흉터를 통해 시간을 본다.

### I11 Re-entry Recognition

수십~수백 화 뒤 첫 1~3문장 또는 한 컷으로 알아볼 앵커.

### I12 Legacy

최종 상태가 `주인공 인벤토리`로 끝나지 않게 한다.

## 4. Character Module

FRONT 캐릭터는 다음을 추가한다.

### 4.1 Body/face

- 대략적 신장 범위는 필요한 경우에만.
- 더 중요한 것: 체형의 기능, 자세, 손, 목, 보행.
- 얼굴 기억점 1~2개.
- 헤어는 색보다 관리방식/직업/생활과 연결.

### 4.2 Clothing

세 층 분리:
1. institution/base garment;
2. job/mission layer;
3. personal deviation.

`전원 같은 군복 + 머리색만 다름` 금지.

### 4.3 Personal object

- 무기일 필요 없음.
- 공구, 기록태그, 의료가위, 낡은 부품, 접은 노선표 등 현재 정본 기능에서 파생.
- 물건이 캐릭터를 설명해야지 새 능력을 만들면 안 됨.

### 4.4 Gesture/voice bridge

기존 Voice Bible과 일치하는 손동작/시선/거리습관 1~2개.

### 4.5 Evolution states

최대 3단계:
- opening;
- mature/mid;
- ending.

옷만 화려해지는 성장 금지. 직위·상처·선택·독립성을 반영.

## 5. Mecha Module

기존 Maneuver Frame Lineup authority를 우선한다.

- lineage silhouette;
- load path;
- head/neck/sensor;
- cooling;
- service access;
- cockpit/cradle;
- weapon stowage;
- CMF;
- wear/damage accumulation;
- pilot fit;
- acquisition/certification;
- maintenance burden;
- independent loss path.

새 능력/무장/변형은 이 패킷에서 만들지 않는다.

## 6. Ship Module

- side/front silhouette;
- engine/radiator/docking geometry;
- frame bay relation;
- one recognizable external scar/patch state;
- bridge/CIC 분리;
- shared living space;
- workshop/medical/cargo tension;
- gravity/noise/smell routine;
- crew personalization;
- module change and visible tradeoff;
- name origin;
- end-state legacy.

## 7. Place Module

### 7.1 Three spatial memories

1. public space;
2. work/service space;
3. private/ordinary space.

### 7.2 Sensory grammar

- gravity or movement;
- ambient machinery sound;
- climate/humidity/temperature;
- dominant public material;
- food/water habit;
- maintenance/cleaning practice.

### 7.3 Landmark rule

랜드마크는 멋진 조형물이 아니라 갈등과 일상에 쓰여야 한다.

예:
- 교통과 시위가 모두 모이는 연결축;
- 병원과 노드 사이의 실제 병목;
- 수리흔적이 쌓인 공공벽;
- 전쟁 때 피난로가 되는 평상시 시장.

### 7.4 State evolution

- first arrival;
- crisis/war;
- recovery/ending.

배경도 흉터를 가진다.

## 8. Weapon/Relic Module

### Weapon/tool

- host/stowage;
- grip/handling;
- sound/recoil/heat;
- ammunition/energy;
- use doctrine;
- counter;
- noncombat use;
- loss/repair.

### Relic/evidence object

- size/material/aging;
- authentication mark;
- damage/repair;
- who made/held it;
- what claim it opens;
- who wants it returned/destroyed/sealed;
- public display vs private custody conflict.

## 9. Exposure Budget

- first appearance: silhouette/behavior + question only.
- second meaningful appearance: cost/barrier.
- third: synergy or unexpected ordinary use.
- later: scar/change.
- payoff: reinterpretation/legacy.

설명문 한 번으로 전체 시트를 소비하지 않는다.

## 10. Pass / Fail

### PASS

- 이름을 가리고도 어떤 대상인지 역할/형상/행동으로 구분 가능.
- 대상의 매력과 비용이 동시에 보임.
- 다시 등장했을 때 변화가 보임.
- 설정집 설명 없이 장면에서 표현 가능.

### FAIL

- 색/등급/출력만 다름.
- 모든 중요 인물에게 전용기체/전용무장 지급.
- 도시가 랜드마크 사진 한 장으로 끝남.
- 함선 내부가 크기만 다른 호텔 복도.
- 유물이 전투 버프 상자.
- `획득` 뒤 더 이상 갈등/유지비 없음.
- 손상/상실이 다음 화에 리셋.

## 1. Rules

- this file pre-registers GA2 major collection states; unregistered major rewards require change control and prior clues.
- project IDs are not all reader-facing names.
- active pursuit remains 3–5 targets at a time.
- people and communities use relationship/authority states, never owned/collected.
- ship upgrades require crew, certification, modules, rights and operating cost.
- a right or institution counts as integrated only when it changes a real operating decision.

Status codes:
- `T` teased.
- `I` identified.
- `C` conditionally claimed/connected.
- `G` integrated and used.
- `L` lost/dispersed/contested.
- `R` reinterpreted.

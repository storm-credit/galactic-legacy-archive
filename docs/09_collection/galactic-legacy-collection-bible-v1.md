## 1. Core Promise

독자는 다음 네 가지 욕구를 동시에 느껴야 한다.

1. **발견:** 실루엣과 기록의 빈칸이 무엇인지 알고 싶다.
2. **획득:** 위험과 비용을 치르고 손에 넣고 싶다.
3. **조합:** 서로 다른 사람·기체·무기·기술을 최적의 팀으로 만들고 싶다.
4. **완성:** 흩어진 계보·사건·문명의 진실을 끝까지 복원하고 싶다.

수집은 단순 소유가 아니다.

> 대상과 접촉하고, 가치를 이해하고, 관계·소유권·운용능력을 확보하며, 그 결과 발생한 책임을 감당하는 과정이다.

## 2. Archive Ontology

《은하유산록》은 물건을 보관하거나 사람을 소환하지 않는다. 미래 역사에서 중요한 흔적을 분류·연결하는 **편향된 기록 인터페이스**다.

### 2.1 Archive functions

- 대상과 기록 흔적의 연관 가능성 표시.
- 미완성 계보·세트·사건 연결 표시.
- 기록 출처와 신뢰도 일부 표시.
- 주인공 개입 이후 기존 기록의 불일치 경고.
- 접촉한 자료를 서로 비교해 모순을 색인.
- 완전히 복원된 기록을 새로운 관점으로 재분류.

### 2.2 Archive non-functions

- 대상의 위치 추적.
- 절대 전투력 표시.
- 사람의 충성·감정 판정.
- 원격 소환·보관.
- 소유권 자동 이전.
- 미래 사건 정답 제공.
- 죽은 사람의 완전 부활.

### 2.3 Activation conditions

기록이 활성화되려면 세 조건 중 둘 이상이 필요하다.

1. `Contact`: 인물·물건·문서·전장 흔적에 직접 접촉.
2. `Context`: 이름·사건·소속·기능 중 하나를 이해.
3. `Resonance`: 주인공의 미래 기억 또는 이미 등록된 유산과 연결.

Rule:
- 멀리 있는 전설을 생각한다고 목록이 열리지 않는다.
- 작가가 필요할 때 갑자기 항목을 생성하지 못하도록 모든 활성화는 장면의 접촉과 정보에 근거한다.

## 3. Record States

각 유산은 다음 단계로 진행한다.

### S0 — Void / 빈칸

- 범주와 수량 또는 존재 흔적만 보임.
- 예: `황혼의 열세 영웅 — ?/13`

Reader effect:
- 완성 욕구와 질문.

### S1 — Rumor / 소문

- 별칭·실루엣·불확실한 업적.
- 서로 모순되는 기록 가능.

### S2 — Trace / 흔적

- 물리적 단서, 전투 데이터, 증언, 부품, 가족관계.
- 아직 대상과 일치 확정 불가.

### S3 — Identified / 식별

- 현재 대상이 미래 기록과 연결될 가능성 확인.
- 신뢰도와 모순 표시.

### S4 — Claimed / 확보

범주별 의미가 다르다.
- 기체·무기: 물리적 통제 또는 합법 소유권 일부.
- 인물: 관계 형성과 공동 목적, 소유가 아님.
- 기술: 이해·복제권 또는 생산 가능성.
- 영토·세력: 조약·정당성·보급 통제.

### S5 — Integrated / 통합

- 팀·함대·기지·정치 체계에서 실제 역할 수행.
- 획득 후 한 번도 쓰이지 않은 대상은 이 단계로 올라가지 못함.

### S6 — Mastered / 숙련

- 장점뿐 아니라 약점·비용·반대교리까지 이해.
- 다른 유산과 새로운 조합 가능.

### S7 — Reinterpreted / 재해석

- 미래 공식 기록의 의미가 뒤집히거나 확장.
- 독자가 수집한 정보가 세계의 진실을 바꿈.

### S8 — Legacy / 계승

- 대상이 주인공 소유로 끝나지 않고 사람·조직·제도에 남음.
- 결말과 문명 질서에 영향을 줌.

## 4. Collection Categories and Different Verbs

모든 범주를 ‘획득’이라는 한 단어로 처리하지 않는다.

### C1. Heroes — 영웅

Collection verbs:
- 발견한다.
- 이해한다.
- 구한다.
- 설득한다.
- 계약한다.
- 동맹한다.
- 인정받는다.
- 떠나보낸다.

Required dimensions:
- 현재 욕망.
- 미래 기록.
- 비극 형성 원인.
- 전투 역할.
- 비전투 역할.
- 합류 조건.
- 이탈 조건.
- 주인공과의 가치관 충돌.

No ownership states:
- `적대 / 관찰 / 거래 / 협력 / 동맹 / 소속 / 독립 / 이탈`.
- 충성도 숫자를 절대값으로 표시하지 않는다.

### C2. Maneuver Frames — 기체

Collection verbs:
- 발견한다.
- 회수한다.
- 복원한다.
- 등록한다.
- 개조한다.
- 배치한다.
- 계승한다.

Required layers:
- 프레임·코어·추진·센서·방열·무장.
- 조종 적합성.
- 정비망.
- 법적 소유권.
- 생산 계보.
- 전임 조종사의 기록.

### C3. Weapons & Modules — 무기·부품

Collection verbs:
- 탈취, 구매, 제작, 해독, 자격획득, 탄약망 확보.

Rule:
- 무기 본체보다 탄약·열·인증·사용교리가 더 희귀할 수 있다.

### C4. Relics & Treasures — 유물·보물

Collection verbs:
- 추적, 발굴, 해독, 조각결합, 봉인, 공개, 반환.

Role:
- 다음 영웅·함선·기술·역사를 여는 열쇠.
- 강한 무기가 아니라 정치적 증거·항로·언어·정통성일 수 있음.

### C5. Ships — 함선

Collection verbs:
- 나포, 인수, 구조, 건조, 계약, 복역, 기함 지정.

Required:
- 함장.
- 승무원.
- 정비·보급.
- 등록·보험·항로권.
- 함선 문화와 과거.

Rule:
- 빈 함선을 얻는 것과 운용 가능한 함대를 얻는 것은 다르다.

### C6. Technologies — 기술

Collection verbs:
- 이해, 재현, 특허, 생산, 교육, 확산, 금지.

Stages:
- 이론→시제품→공정→인력→보급→교리→사회확산.

Rule:
- 설계도 하나로 산업이 생기지 않는다.

### C7. Factions & Institutions — 세력·제도

Collection verbs:
- 보호, 승인, 연합, 개혁, 합병, 분리, 대표권 획득.

Rule:
- 세력을 포켓처럼 소유하지 않는다.
- 내부 파벌과 지역이 별도 의사를 유지.

### C8. Territory, Nodes & Civilizations — 영토·노드·문명

Collection verbs:
- 해방, 점령, 신탁, 통행권, 시민권 통합, 조약, 복원.

Required:
- 주민 동의 또는 강제의 정도.
- 보급·법·정당성.
- 유지비와 방어.
- 이전 소유자의 권리.

## 5. Multi-Axis Rarity

단일 `SSR > SR > R` 등급을 정본으로 사용하지 않는다. 유산은 다섯 축으로 평가한다.

1. `Scarcity`: 얼마나 드문가.
2. `Historical Weight`: 역사에 남긴 영향.
3. `Operational Value`: 현재 임무에서의 실제 가치.
4. `Integration Cost`: 운용·정비·정치 비용.
5. `Record Certainty`: 기록이 얼마나 믿을 만한가.

Display example:

```markdown
Legacy: 미확인 황실 프레임
Scarcity: Extreme
Historical Weight: Disputed
Operational Value: Low — current condition
Integration Cost: Severe
Record Certainty: 31%
```

Reader effect:
- 희귀하지만 당장 쓸모없거나, 흔하지만 결정적 역할을 하는 대상을 만들 수 있다.

## 6. Collection Currencies — Narrative Resources

숫자 재화창 대신 수집을 가능하게 하는 현실 자원을 관리한다.

### Access

- 시설·도크·자료·인물에게 접근할 권리.

### Trust

- 동료와 기관이 위험을 함께 감수할 이유.

### Legitimacy

- 소유권, 계급, 시민 지지, 법적 승인.

### Capacity

- 정비사, 승무원, 생산시설, 의료, 보급.

### Intelligence

- 위치가 아니라 맥락·약점·진짜 가치.

### Material

- 부품, 연료, 탄약, 돈, 희귀재료.

### Time

- 연구·수리·설득·훈련에 필요한 기간.

Rule:
- 주요 수집은 최소 두 자원을 소비한다.
- 돈만 있으면 모든 것을 살 수 없고, 신뢰만으로 함선을 띄울 수 없다.

## 7. Acquisition Loop

Standard loop:

1. `Tease`: 실루엣·소문·빈칸.
2. `Contradiction`: 알려진 기록과 현재가 다름.
3. `Investigation`: 사람·장소·기술의 맥락을 확보.
4. `Commitment`: 다른 목표를 포기하고 비용을 지불.
5. `Contest`: 적·제3세력·소유자와 충돌.
6. `Claim`: 관계·소유권·접근권 일부 확보.
7. `Complication`: 유지비·부작용·새 적·도덕 문제.
8. `Integration`: 실제 임무와 팀에 배치.
9. `Reinterpretation`: 미래 기록의 의미 갱신.

Anti-fetch-quest rule:
- 좌표로 가서 전투 후 줍는 구조를 연속 사용하지 않는다.
- 획득 방식은 설득, 법정, 구조, 경매, 탐험, 나포, 제작, 계승, 거래, 공개 중 순환한다.

## 8. Set Systems

### 8.1 Lineage Set — 계보 세트

Example:
- 같은 조선소·설계자·기사단·황실 계보의 기체·무장·기록.

Completion reward:
- 숨은 호환, 생산기술, 역사 진실.

### 8.2 Event Set — 사건 세트

Example:
- 오르페우스 피난선단의 함선·증언·통행기록·구조신호.

Completion reward:
- 사건의 책임과 선택지를 재구성.

### 8.3 Functional Set — 역할 조합

Example:
- 정찰기+전자전 영웅+저신호 센서+중립항로 지도.

Reward:
- 새로운 임무 해결 방식.

### 8.4 Relationship Set — 관계 세트

Example:
- 서로 적이었던 에이스, 정비사, 함장.

Reward:
- 자동 버프가 아니라 협동전술·공동결정·감정적 회수.

### 8.5 Civilization Set — 문명 복원

Example:
- 언어, 항법, AI 인격, 유적, 후손 공동체.

Reward:
- 문명을 전투력으로 소비할지 자치권을 인정할지 선택.

Set rule:
- 완성은 능력치 보상만이 아니라 새 정보·권리·책임을 연다.

## 9. Roster and Synergy

### 9.1 Role taxonomy

Combat roles:
- 돌파, 방어, 정찰, 전자전, 저격, 구조, 나포, 지휘.

Non-combat roles:
- 정비, 의료, 법, 외교, 정보, 생산, 교육, 문화, 항법, 금융.

Character design rule:
- 핵심 영웅은 전투 역할 1개와 비전투 역할 1개를 가진다.
- 전투력이 낮아도 조직 기능을 바꾸면 높은 수집 가치가 있다.

### 9.2 Synergy sources

- 장비 호환.
- 교리와 지휘관.
- 과거 관계.
- 언어·문화.
- 법적 신분.
- 신뢰와 갈등.
- 임무 환경.

### 9.3 Anti-perfect-party rule

- 모든 임무에 최적인 고정팀은 없다.
- 부상·외교·정비·다른 전선 때문에 인물이 분산.
- 주인공이 최강 인물만 독점하면 다른 지역과 기관이 약해지는 비용 발생.

## 10. Loss, Damage and Recovery

### Heroes

Possible loss:
- 사망, 부상, 이탈, 배신, 은퇴, 정치적 체포, 독립.

Recovery:
- 관계 복구, 치료, 법적 구출, 역할 변경.
- 죽음은 기본적으로 되돌리지 않는다.

### Frames / Weapons

Possible loss:
- 파괴, 나포, 등록말소, 부품고갈, 조종사 부적합.

Recovery:
- 잔해 회수, 재설계, 계승기, 일부 부품 재사용.

### Ships / Territory

Possible loss:
- 침몰, 승무원 이탈, 보험·등록 박탈, 주민 반란, 보급 단절.

Rule:
- 손실은 도감 항목 삭제가 아니라 역사 상태 변경으로 기록.
- 잃은 대상이 다른 세력에서 다시 등장할 수 있다.

## 11. Anti-Power-Creep Rules

1. 새 장비는 새로운 역할을 열고 새로운 부담을 만든다.
2. 전투력 상승보다 정보·접근·생산·정당성 증가를 병행한다.
3. 구형 장비는 정비성·추적회피·호환·단순성의 가치가 남는다.
4. 적도 주인공의 조합을 분석하고 대응교리를 개발한다.
5. 유산기 한 대가 함대·보급·승무원을 대체하지 못한다.
6. 초월기술은 사용 비용·법·문명적 대가를 가진다.
7. 주인공은 모든 최고 장비의 최적 조종사가 아니다.
8. 한 시즌의 강점은 다음 시즌의 환경에서 약점이 될 수 있다.

## 12. Reveal and Feedback Language

유산록 표시는 짧고 기능적이어야 한다.

### Tease display

```text
[미확인 계보 반응]
황실 기동프레임: 1/7
기록 신뢰도: 18%
```

### Contradiction display

```text
[기록 불일치]
사망 연도와 현재 생체기록이 일치하지 않습니다.
가능성: 동명이인 / 계승명 / 기록 조작
```

### Claim display

```text
[관계 갱신]
H-001은 당신의 지휘를 따르지 않습니다.
다만 이번 임무의 목적에는 동의했습니다.
```

### Loss display

```text
[유산 상태 변경]
함선 등록: 소유 → 적대세력 나포
계보는 유지됩니다.
```

Rules:
- 감정적 장면의 절정에 긴 설명창을 띄우지 않는다.
- UI는 장면을 해석하지 않고 새로운 질문을 남긴다.
- 한 장면에 핵심 알림 1~2개가 기본.

## 13. Reward Cadence

### Micro reward — 1~3 episodes

- 단서, 접근권, 관계 변화, 부품, 작은 선택권.

### Minor completion — 5 episodes

- 실제 사용 가능한 기능·권리·동료 협력.

### Arc reward — 15~30 episodes

## 16. Archive Risk and Cost

유산록 사용에 게임식 마나를 붙이지 않는다. 대신 정보와 정체성 비용을 둔다.

### Cognitive conflict

- 현재 인물과 미래 기록을 겹쳐 보며 오판·죄책감이 생김.
- 기록이 강할수록 주인공이 현재 사람을 미래 역할로 환원할 위험.

### Exposure

- 특정 고대 인터페이스와 정보기관이 유산록 반응을 탐지할 수 있음.
- 자주 공개적으로 활용하면 주인공의 정보원이 의심받음.

### Memory contamination

- K4 기록과 개인 K1 기억의 경계가 일부 흐려질 수 있음.
- 중요한 장면은 별도 증거로 재검증해야 함.

### Historical displacement

- 개입 후 기록은 소실·충돌·재배열.
- 완성 직전 세트가 다른 의미로 바뀔 수 있음.

Rule:
- 유산록은 주인공을 강하게 만들면서 동시에 사람을 기록대로 보게 만드는 내적 적이다.

## 17. Ethical Rules

- 인물 등록은 합류·소유가 아니다.
- 유산록에 낮게 평가된 인물도 존엄과 선택권을 가진다.
- 미래의 범죄 기록만으로 현재 인물을 처벌하지 않는다.
- 문명 유산은 약탈품이 아니라 후손·소유권·보존 책임을 가진다.
- 수집 완성보다 대상의 자율성을 선택하는 결말이 가능해야 한다.

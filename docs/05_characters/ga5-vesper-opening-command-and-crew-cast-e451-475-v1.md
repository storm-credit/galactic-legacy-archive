- FC-002 `시라 케온 / Sira Keon` — provincial/local-defense admiral.

## 2. Ardo Rev

Current role:
- commander of Legion Vanguard elements and strongest coherent military-command advocate at Vesper.

Immediate goal:
- prevent another thirteen-minute authorization delay and preserve a single tactical succession chain.

Useful truth:
- his equal-assumption reconstruction is operationally credible; central command likely reacts 8–10 minutes faster.

Danger:
- battle command can capture ammunition, repair, routes and appointments indirectly even without hull title.

Voice:
- objective, unacceptable loss, time to decision, reserve and succession.

Independent actions E451–475:
- accepts only 62% of requested safe ammunition instead of seizing the magazine;
- builds the external screen independently;
- offers Rian real authority rather than theatrical recognition;
- records the cost of distributed delay without becoming a cartoon tyrant.

E475 state:
- supports alert-window default battle command and stronger Charter command clause;
- does not own or command all Vesper formations;
- remains a mentor-rival and possible Charter participant/opposition.

## 1. Executive Ruling

### 1.1 왜 이 등록부인가

항목 카탈로그가 저장소를 항목 단위로 세자 병목이 드러났다.

| 분야 | 등록 항목 |
|---|---:|
| C1 영웅·관계 | 115 |
| C7 세력·제도 | 88 |
| C8 영토·노드 | 58 |
| C5 함선 | 48 |
| **C3 무기·부품** | **5** |

수집형 연재에서 10개 대액트를 통틀어 무기·부품 항목이 다섯이다. 초반 100화가 기체 한 대로 굴러가는 구간이라, 이 축이 비면 **성장이 출력 상승으로만 표현된다** — CLAUDE.md §7 중지 조건 "전투 승리가 출력 상승이나 각성만으로 반복된다"의 전 단계다.

### 1.2 지어내지 않는다

**기능족은 이미 정본이다.** [[weapons-sensors-acceleration-calibration-v1]] §7이 W1–W12를 성능 봉투와 함께 확정해 뒀고, C3 감사의 기준선 `12_CANON_FUNCTION_FAMILIES`가 이것이다. 기체가 L01–L08 계보 안에 슬롯을 채운 것처럼, 이 등록부는 **W1–W12 안에 개체를 명명**한다.

07호의 개막 무장 4종도 이미 정본이다 ([[first-frame-bible-v1]] §5). 이 등록부는 그것을 **등록만 하고 새 이름을 붙이지 않는다.**

### 1.3 계수 분리 (§15-7)

| 셈 | 이 문서 | 의미 |
|---|---:|---|
| 명명 앵커 | **44** | 독자가 이름으로 부를 수 있는 개체 |
| 그중 정본 | **4** | 07호 개막 도구. 새 이름 없음 |
| 그중 제안 | **40** | 전부 승인 대기 |
| 정본 기능족 | 12 | W1–W12, 이미 정본 |
| 표준 장비 유형 | 미등록 | 배경 밴드 28–42, 개체 명명 대상 아님 |
| 탄약·개장·운용·상실 상태 | 미등록 | 상태 밴드 80–120, 개체 수에 더하지 않는다 |

밴드 40–64 안이며 하한 쪽이다. 무장은 기체·함선과 달리 **한 개체가 여러 호스트를 옮겨 다니므로**, 이름 수보다 적합표가 더 많은 일을 한다.

## 2. Naming Grammar

### 2.1 형식

`<제조계보><W족>-<블록>` + 통칭. 예: `IR-W03-2 PILUM / 필룸`.

| 접두 | 제조계보 | 어근 | 왜 |
|---|---|---|---|
| `OS` | 07파생 개방규격 (L01) | **번호 우선, 통칭 없음** | 개방규격은 이름을 자랑하지 않는다. 07호가 번호로 남는 것과 같은 이유다 |
| `IR` | 제국 (L02) | 라틴 | 무기에까지 법과 계보의 언어를 쓴다 |
| `HX` | 헬릭스 인증권 (L03) | 그리스 | 규격과 측정의 어원 |
| `AD` | 아르디스 개방브릿지 (L04) | 라틴 실무어 | 공방의 도구 이름 |
| `NA` | 중립 구조망 (L05) | 그리스 | 헬릭스와 같은 뿌리, 다른 목적 |
| `BRN` | 변경 재조립 (L06) | 북유럽 | 서약과 생존의 언어 |
| `CS` | 연속성·팰림프세스트 (L07) | 라틴 | 기록 권위를 주장하는 조직 |

[[decision-log]] D-20260813-02의 진영 어근을 그대로 확장한다. **개방규격만 통칭이 없는 것이 설계다** — 이름 없는 규격이 가장 널리 퍼진다.

### 2.2 금지

1. 기체 하드 리젝트 목록을 그대로 적용한다 (`ORIGIN` `GENESIS` `OMEGA` `APEX` `PRIME` `LEGACY` 등 최상급 일체).
2. `오르페우스`를 비롯한 작전·사건명을 무기에 쓰지 않는다.
3. 정본 인명·기체명·선체명과 유사음 동시 등장 금지. **이 문서에 기체·선체 통칭을 옮겨 적지 않는다** — 클리어런스 검사가 저장소 전체를 훑는다.
4. 07호 개막 4종은 개명하지 않는다.

## 3. Host Fit — 무엇에 붙는가

기체 46슬롯·함선 41행과 무장을 잇는 표다. **개체가 아니라 급수 단위**로 정한다.

| W족 | 규모 | 붙는 호스트 | 제약 |
|---|---|---|---|
| W1 방어 레이저 클러스터 | 함 | `CR` `LN` `CV` `DE` | 근거리 정밀, 사거리에 급격히 약해짐 |
| W2 운동 근접방어포 | 함 | 전 급수 | 종말 요격·파편 정리, 탄약 소모 큼 |

| W4 유도 탄두 | 함 | `LN` `CR` `DE` `FR` | 장거리 주력, 포화 사격 |
| W5 배회·계전 탄약 | 함/기 | `CV` `SV` + 기체 외부 장착 | 체공 시간이 곧 정보 |
| W6 입자·하전 빔 | 함 | `LN` `CR` | 대기·차폐에 취약 |
| W7 척추 레이저 | 함 | `LN` 전용 | 충전·재순환 중 발사함이 노출됨 |
| W8 기체 카빈·코일 | 기 | 전 계보 | 관절·센서·노출부 겨냥 |

| W10 개방·절단·구조 도구 | 기 | 전 계보, `L01` 우선 | **목표가 노드·거주구·기록·배·사람일 때 파괴 화력보다 가치가 크다** |

**여기서 갈등이 나온다.** 노획 무장은 호스트의 인증 체계를 통과하지 못한다. 제국 카빈을 변경 기체에 달면 발사는 되지만 사격통제가 붙지 않고, 붙이려면 인증을 위조하거나 정비선을 세워야 한다.

## 5. Reader Exposure — 권위 위임

### 노출 — 정본 예산을 따른다

**이 등록부는 자기 노출 상한을 갖지 않는다.** 독자 기억 권위는
[[reader-facing-terminology-phonetics-and-register-bible-v1]] §2이며 예산은 거기 있다.

| 회차당 | 값 |
|---|---|
| **총 고유명 최초 사용** | **0–4** |
| 활성 장소 | 1–3 |
| 활성 기관·세력 | 1–3 |
| 신규 기술 용어 | 0–2 |
| 10화 창 기준 활성 수집 목표 | 3–5 |

초안은 등록부마다 장면당 상한을 따로 뒀고 합계가 21이 됐다. 회차당 4개인 정본에
대해 장면당 21개였다 — 국소 판단 여섯 번이 합쳐질 때를 보지 않은 결과다
([[registry-redteam-2026-08-13]] D1).

**첫 등장에는 종류어를 붙인다.** 어근이 진영은 구별하되 종류는 구별하지 못하므로
문장이 구별한다 — `전열함 유덱스`, `카빈 사기타`, `규격 노르마`, `봉인 열쇠
클라비쿨라`. 재등장부터는 생략한다 (D2).

아래 전면/배경 구분은 **예산 안으로 들어올 자격이 있는 항목의 목록**이며,
몇 개를 부를 수 있는가의 허가가 아니다.

## 6. Collection Desire Hooks

| 욕구 | 이 등록부에서의 형태 | 붙는 비용 |
|---|---|---|
| 발견 | 잔해장의 낯선 형식 각인, 인증 등급이 지워진 총열 | 오판, 조사 시간, 소지 자체의 위험 |
| 획득 | 노획·양도·제작·인증 통과 | 인증 위조의 법적 결과, 탄약 수급, 정비 시간 |
| 조합 | 호스트 적합표(§3)를 통과하는 새 조합 | 사격통제 미연동, 무게중심 변화, 열 |
| 완성 | 한 계보의 W족을 다 갖추면 **정비·보급을 단일화**할 수 있다 | 그 계보에 묶인다. 계보가 무너지면 전부 멈춘다 |

**완성이 최강을 뜻하지 않는다.** 한 계보로 통일하면 운용이 쉬워지고 정치적으로 종속된다.

## 7. Open Decisions

1. **탄약·열·인증·보급 연결** — C3의 `HOLD` 사유다. 개체별 수치는 아직 없다.
2. **표준 장비 유형 28–42** — 이름 없는 배경 장비의 등록 여부. 지금은 미등록이다.
3. **07호 4종의 진화 경로** — [[first-frame-bible-v1]] §8 복원 트랙과 대조가 필요하다.
4. **회차 카드 대조** — §4의 첫 등장은 액트맵과만 대조했다. 회차 카드 수준 확인은 해당 구간 설계 세션의 몫이다.

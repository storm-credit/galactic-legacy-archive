## 1. Non-Negotiable Boundary

이 오버레이가 할 수 있는 것:

- 기존 카드에 이미 존재하는 사람/역할/공동체를 반복 foregrounding;
- 기존 함선·기체·화물·노드·병원·릴레이·작업장·기록매체·서비스 설비를 장면의 physical anchor로 선택;
- 기존 결정의 결과를 같은 화 또는 다음 화에서 사람이 체감하도록 배치;
- 기존 Voice/visual/sensory identity를 재사용;
- 설명 순서를 `현상 → 선택 → 설명`으로 바꿈.

할 수 없는 것:

- 새 사건 추가;
- 새 사망/부상/손실 추가;
- 기존 사망·영구손실 복구;
- 새 기술·능력·권한 생성;
- 새 종족/세력/기사단/함선/기체/유물 추가;
- 기존 숫자 변경;
- Rian에게 local/medical/identity/Archive authority를 흡수;
- exact named focal을 정본으로 새로 고정.

[ASSUMPTION]
- 필요한 현재 인물 carrier가 카드에 역할로만 존재하고 이름이 없으면, 원고 배치 단계에서 먼저 기존 cast registry와 대조한다. 이름 추가가 필요하면 별도 작가결정/정본절차로 멈춘다.

## 2. HAPΔ Scene Translation Rule

### H — FACE FIRST

추상 문제를 먼저 인물의 현재 문제로 보여준다.

Examples of functions, not prose:
- route policy → 약/필터/가족연락을 기다리는 current worker/caregiver;
- archive right → 번역/정비/보관을 실제 직업으로 하는 custodian;
- credential rule → 수리/승선/진료/급여가 막히는 current person;
- command field → 함장이 받는 서로 다른 명령과 실제 진입창.

### A — HAND / HARD ASSET

최소 하나는 장면에서 위치와 상태가 있어야 한다.

Prefer existing:
- ship / frame / tug / service craft;
- cargo pallet / medicine / filters / power parts;
- relay / cooling / receiver / repair equipment;
- archive object / current log / custody package / existing interface;
- hospital bed / workshop / habitat service system.

Do not invent exotic artifact technology merely to make a document physical.

### P — PLACE

회의실이 필요해도 그 회차의 기억점이 회의실일 필요는 없다.

Prefer:
- where the rule currently matters;
- where people wait/work/repair/move;
- where a ship or record is physically held;
- where a local actor can say no.

### Δ — SHOW THE CHANGE

Preferred order:

1. current baseline;
2. decision or rule;
3. physical/service consequence;
4. actor response/refusal;
5. only then system explanation if still needed.

Bad execution:
`새 규칙을 승인했다 → 다음 문단에서 조항 설명`.

Better execution pattern:
`current service/ship/person 상태가 바뀐다 → 누가 멈추거나 받아들인다 → 왜 그런 authority였는지 설명`.

## 3. Five-Episode Window Check

Most five-episode windows in HIGH WATCH bands should answer:

- **FACE**: 지금 누가 무엇을 원하거나 거부하는가?
- **HARD ASSET**: 무엇을 실제로 타고/옮기고/고치고/잃고/막는가?
- **PLACE**: 어디에서 벌어지는가?
- **DELTA**: 화 끝에 무엇이 실제로 달라졌는가?
- **COST**: 누가 시간/물자/신뢰/건강/자율성을 잃는가?
- **REENTRY**: 이전에 알던 사람/배/장소/상처가 돌아왔는가?

5화마다 반드시 새 물건이 나올 필요는 없다. **같은 물건/사람이 다른 상태로 재등장하는 것이 더 강한 수집욕**이다.

## 8. Recurring-Carrier Rule

Late-series abstraction is best solved by **reuse**, not expansion.

When possible within approved cards:

- same person appears under multiple consequences;
- same ship returns with accumulated repair/scar/status;
- same clinic/workplace/relay appears before and after policy;
- same record has different custody/use states;
- same community benefits from one central feature and is harmed by another;
- same local actor who stopped Rian earlier can later cooperate without becoming subordinate.

Target reader effect:

> `새 설정을 또 배웠다`가 아니라 `내가 아는 사람/배/장소가 이제 이렇게 됐다`.

## 10. Draft Audit Questions

For every HIGH WATCH episode draft:

1. 첫 300~600자 안에 독자가 볼 수 있는 사람/공간/물건이 있는가?

- tangible execution requires a new death/injury;
- a recurring current person needs a new canonical relationship;
- a physical anchor needs a new technology/capability;

Then report:
1. problem;
2. cause;
3. alternatives;
4. recommendation;

# Episode 115 — 고쳐야 할 것과 버려야 할 것

Date:
- CY 742-07-04.

POV:
- 하렌, translating mission promises into passenger, cargo and community consequences.

Opening state:
- repair funding exists only for a minimum configuration;
- all departments submit “essential” requests exceeding budget, heat, space and labor.

Visible goal:
- approve a repair/module package that can earn a restricted transit certificate.

Hidden pressure:
- each faction expects its contribution to produce a preferred future use: weapons, data, patients, cargo or technical standards.

## Scene 115.1 — Capacity board

Location:
- cargo bay with actual module footprints marked on deck.

Requests:
- 리안: basic tactical survival and sensor/PD reliability;
- 하렌: passenger and community movement margin;
- 네라: workshop and 07 cradle;

- 테오: cargo capacity and revenue;
- 루카: mass and route margin;

## Scene 115.2 — Four impossible packages

Options:
1. tactical package — better PD/missiles, weak passengers/workshop;
2. refugee package — more berths, weak repair and route service;
3. workshop package — repair/07 support, reduced passengers/cargo;
4. relay package — future Silex value, insufficient current crew and income.

State change:
- no package fulfills every promise.

## Scene 115.3 — Rian loses the weapons vote

Action:
- 리안 argues that a ship unable to survive attack cannot protect anyone;
- 마렌 and 베라 show that weapons cannot fire safely with current cooling;
- 테오 shows offensive load raises insurance and contract restrictions.

Decision:
- heavy/offensive weapon restoration deferred;
- only tested PD, decoys, rescue/tag payloads retained.

## Scene 115.4 — Minimum configuration

Selected:
- Reactor A/common-trunk isolation;
- one safe drive/control chain;
- recycler and basic monitored medical capacity;
- basic workshop;
- Bay 1/07 cradle;
- multi-signature comms/auth;
- reduced cargo and passenger conversion.

Deferred:
- Reactor B full restoration;
- Bay 2;
- full hospital/refugee module;
- relay-service module;
- offensive missile/EW package;
- crew-drum complete overhaul.

Decisive choice:
- board approves a ship that can work and rescue locally but cannot fight or carry everyone.

Immediate result:
- work packages and resource owners assigned.

Reward:
- executable minimum-repair plan.

Cost:
- tactical weakness, limited passengers and no second frame;
- groups expecting priority feel betrayed.

Collection state:
- G2-S03/S06/S08/S11 active;
- G2-S07/S09/S10/S13 deferred/teased.

Relationship state:
- 리안 accepts institutional defeat rather than secretly preserving combat priority.

Carried state:

Final hook:

# Episode 116 — 한 번 작동하는 것

Date:
- CY 742-07-06.

POV:
- 베라.

Opening state:
- hybrid isolation installed as provisional test article;
- Reactor A cannot yet provide transit power.

Visible goal:
- prove Reactor A can reach and repeat safe trial output without relying on Reactor B.

Hidden pressure:
- one successful run would satisfy political/media expectations but not maintenance or certification.

## Scene 116.1 — Hot-test ladder

Location:
- engineering, radiator roots and berth heat sink.

Test sequence:
- 20%, 40%, 60%, 75% output;
- each stage requires pressure, material expansion, sensor and manual-isolation verification.

Action:
- 네라 monitors local mechanical response;
- 베라 controls whole-system stop;
- old workers compare current vibration with class history.

## Scene 116.2 — Works once

Result:
- test reaches 75%;
- one seal and controller compensation drift beyond repeatability margin;
- no catastrophic leak.

Conflict:
- Academy observer calls the run successful;
- 베라 records “successful single run, not certified repeat operation.”

State change:
- functional, repeatable, maintainable and certifiable are explicitly separated.

## Scene 116.3 — Repair versus schedule

Options:
- replace the seal/controller and lose two days;
- accept restricted lower output and preserve schedule;
- borrow a certified module with expanded Helix inspection rights.

Decision:
- hybrid replacement + lower certified output;
- no increase in Helix remote authority.

## Scene 116.4 — Reactor A envelope

Locked trial output:
- stable 82–86% of current derated rating;
- enough for transit, life support, one-frame service and limited defense, not simultaneous peak demands.

Decisive choice:
- ship accepts lower power instead of hiding the failed repeatability test.

Reward:
- Reactor A enters provisional transit path.

Cost:
- contingency budget reduced;
- schedule slips and Reactor B stays isolated.

Collection state:
- G2-S03 Reactor A: `C`, awaiting route certificate;
- G2-S05 bypass: integrated with inspection burden.

Mystery state:
- SM-04 fully retired at technical level: no true reactor redundancy.

Relationship state:
- 베라’s refusal to celebrate protects 네라’s design from being misrepresented as final.

Carried state:
- propulsion/attitude test must use the derated envelope.

Final hook:
- at 8% commanded port translation, the ship rotates before it translates.

Specialist panel:
- H04/H06/T04, M05, P02/P03, C04, X01/X04.

# Episode 117 — 오른쪽으로만 미는 배

Date:
- CY 742-07-08.

POV:
- 루카.

Opening state:
- Reactor A provisionally stable;
- propulsion controller mismatch remains.

Visible goal:
- establish a predictable handling envelope for berth release and route approach.

Hidden pressure:

## Scene 117.1 — Restrained attitude test

Location:
- external berth truss with tug restraint.

Action:
- command low-power yaw, translation and stop sequences;
- physical markers, tug loads and independent sensors record response.

Result:

Action:
- 리안 predicts a correction based on later standardized fleet software;
- current controller interprets the command differently.

Consequence:
- berth restraint absorbs the movement, damaging one fixture and creating a 9,800 BSC claim;
- no injury.

State change:
- current route pilot and engineer outrank remembered future handling.

## Scene 117.3 — Mechanical/software split

Findings:
- two clusters mechanically acceptable;
- mismatched replacement controllers use different response curves;
- full replacement unavailable.

Repair:
- common command translation layer;
- manual asymmetry table;
- lower thrust limit;
- no autonomous close maneuver without local verification.

## Scene 117.4 — Handling acceptance

Decisive choice:
- 루카 accepts a slower certified handling profile instead of using opaque auto-correction;
- 마렌 signs only for restricted mass and acceleration.

Reward:
- one reliable transit/approach control chain.

Cost:

- slower docking and poor pursuit;
- berth claim and further contingency loss.

Collection state:

- no weapon/combat upgrade.

Relationship state:
- 리안 must rely on 루카’s current route and control knowledge;
- 루카’s side obligation remains disclosed but unresolved.

Carried state:

Final hook:

# Episode 952 — 네 개의 승리안

Date:
- CY 747-04-04 to 04-06.

Goal:
- compare real alternatives before selecting authority.

Packages:
- P1 plural regional command: strongest local control, slowest cross-node synchronization;
- P2 coalition schedule key plus named fleet commands: moderate speed, fragmented service authority;
- P3 temporary central command key with separated service/credential/local/review authorities;
- P4 full Seed-style command and credential fusion: fastest simulated response, broadest false-positive and status risk.

- P4 remains faster in some simulations but conflicts with current law and affected standing;
- no package guarantees minimum death.

Decision:
- advance P3 for public and institutional authorization.

Reward:
- central command is selected against actual alternatives.

Cost:
- supporters of P4 call the limits performative weakness.

Hook:
- the coalition must define what the central key is and is not.

# Episode 953 — 다섯 권한을 한 사람에게 주지 않는다

Date:
- CY 747-04-07 to 04-09.

Goal:
- design the temporary key through separated fields.

Five fields:
1. common fact/model and package version;
2. military/mission command;
3. service/affected priority and current standing;
4. credential routing plus local physical/medical/ship/receiving stops;
5. independent review, logging and expiry.

Rian may receive:
- field 2 command composition and authenticated execution;
- access to approved package outputs and live facts.

Rian may not receive:
- unilateral fields 1, 3, 4 or 5;
- citizenship/personhood/family/culture/reproduction/technology authority;
- deletion;
- permanent classification;
- command over nonparticipants.

Decision:
- name the instrument `중앙연속성 지휘키 / Central Continuity Command Key`.

Reward:
- Rian can issue synchronized orders without becoming the source of every premise and permission.

Cost:
- key operation depends on other authorities remaining available during attack.

Hook:
- member and affected institutions vote by function rather than one total accession vote.

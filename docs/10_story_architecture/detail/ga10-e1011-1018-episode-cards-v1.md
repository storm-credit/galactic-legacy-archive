# Episode 1011 — 열린 규격이 다시 필요한 이유

Date:
- CY 747-05-27 to 05-29.

Goal:
- prevent distributed modules from becoming incompatible private islands.

Problem:
- four fact/model mirrors produce diverging package versions;
- credential gateways use different expiry formats;
- service councils encode priorities differently;
- one local return package cannot be read by another node.

H-002/open-standard institutional response:
- publish interoperable schemas, version provenance and safety conformance;
- preserve local extensions and refusal;
- prohibit one vendor or institution from owning compatibility.

Decision:
- adopt `Open Continuity Interchange v1` for transition use.

Reward:
- distributed custody can communicate without one central database.

Cost:
- public standards expose attack surfaces and require slower review.

Hook:
- Neutral legal institutions test whether technical compatibility is enough without enforceable rights.
